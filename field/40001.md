# 字段 `40001` — 消息全局唯一 ID

| 属性 | 值 |
|------|-----|
| 字段编号 | 40001 |
| 类型 | INTEGER |
| 所属表 | c2c_msg_table |
| 主键 | ✓ |
| 置信度 | ✅ 高（基于 131 万行统计验证） |

## 含义

**消息全局唯一标识符（msg_uid）**：每条消息在整个 QQ 系统中的唯一编号，由服务端分配。

## 特征

| 特征 | 结果 |
|------|------|
| 全表重复行数 | **0**（131 万行严格唯一） |
| 值域 | `7436569264759096330` ～ `7639058395275417231` |
| 十六进制范围 | `0x673400587D8DC40A` ～ `0x6A03632314DB568F` |
| 与时间（40050）单调性 | 按 40001 升序时，40050 单调不减比例 **94.4%** |
| Snowflake 高位时间戳 | **不适用**（标准 Snowflake shift=22 偏差达 2 亿秒，与 40050 不匹配） |

## 说明

- 40001 是表的主键，在全表 1,318,588 行中零重复，是消息的唯一索引依据。
- 数值与发送时间正相关（94.4% 单调），说明 ID 近似按时间递增分配，但并非严格有序（存在跨会话 / 客户端时钟漂移导致的乱序）。
- 不符合标准 Snowflake ID 结构（高位不直接编码毫秒时间戳），推测为 QQ 自研的 64 位 ID 方案。
- 与 40003 的 Pearson 相关系数为 **-0.43**，二者独立性较高，底层生成逻辑不同。
