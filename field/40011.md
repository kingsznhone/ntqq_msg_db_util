# 字段 `40011` — 消息内容类型

| 属性 | 值 |
|------|-----|
| 字段编号 | 40011 |
| 类型 | INTEGER |
| 所属表 | c2c_msg_table |
| 置信度 | 🔍 中（基于消息体大小、方向分布及 40012 绑定关系推测） |

## 含义

**消息内容类型（Content Type）**：标识消息携带的是哪种媒体或交互内容，类似 MIME type。决定了 `40012` 的可取值空间。

## 取值说明

| 值 | 行数 | 消息体均值 | 推测含义 | 说明 |
|----|------|-----------|---------|------|
| `2` | 1,309,933（99.3%） | 100B | **标准消息** | 文本、图片、表情包、语音条等，通过 `40012` 位掩码进一步区分 |
| `3` | 2,408 | 250B | **文件传输** | `40012` 取多种值，对应文件传输的不同状态（待传/进行中/完成/失败） |
| `9` | 1,794 | 288B | **表情回应（Reaction）** | `40012` 恒为 `0x0021`；96.6% 为收到方向，几乎全为对方发出的回应 |
| `6` | 930 | **固定 162B** | **名片/联系人分享** | 消息体大小完全固定，结构高度规整，`40012` 恒为 `0` |
| `7` | 876 | 307-383B | **位置分享** | 收发两种固定大小（约 307B / 383B），`40012` 恒为 `0` |
| `11` | 640 | 974B | **合并转发消息** | 消息体较大（451-1579B），`40012=0` 为主；含 `40013=5/40012=7` 的子集 |
| `5` | 531 | 293B | **系统/通知类** | 同时出现于 `40013=3`（系统消息），`40012` 含特殊值 12/15 |
| `8` | 492 | 894B | **语音消息** | 消息体 700-1353B，大小分布集中，`40012` 恒为 `0` |
| `17` | 417 | 138B | **消息状态通知** | `40012` 恒为 `0x0008`（bit3），体积小且高度一致（122-179B） |
| `0` | 390 | —（NULL） | **无效/已删除消息** | 消息体几乎全为 NULL |
| `1` | 126 | —（NULL） | **无效/已删除消息** | 消息体大部分为 NULL |
| `19` | 32 | 96B（固定） | **戳一戳 / 互动通知** | 消息体极小且固定 |
| `10` | 18 | 491B | **视频通话记录** | `40013=2`（自发特殊）占多数，消息体中等 |
| `31` | 1 | 10132B | **超长/特殊消息** | 单条，不具统计意义 |

## 关键规律

- **`40011` 决定 `40012` 的可取值空间**：`40011≠2` 时，`40012` 几乎固定为某个特定值，不是自由组合的位掩码
- `40011=2` 是唯一一种 `40012` 真正作为 bitmask 自由叠加的情况
- bit12（`0x1000`，长消息标志）**仅在 `40011=2` 下出现**，其他类型均不含此 bit

## 关联字段

| 字段 | 关系 |
|------|------|
| `40012` | 属性标志位，含义受 `40011` 约束 |
| `40013` | 发送方向，与 `40011=9` 高度相关（回应消息几乎全为收到） |
| `40800` | 消息体，大小特征与 `40011` 强关联 |
