# 字段 `40105` — 已读/送达标志

| 属性 | 值 |
|------|-----|
| 字段编号 | 40105 |
| 类型 | INTEGER |
| 所属表 | c2c_msg_table |
| 主键 | — |
| 置信度 | ❓ 低（仅方向关联强，无法从消息体直接验证） |

## 含义

**发送侧已读/送达标志**：仅在自己发出的消息（40013=1/2）中可能为 `1`，接收消息（40013=0/3）恒为 `0`。推测 `1` 表示该消息已被对方确认（已读或已送达），但具体语义无法从当前数据直接验证。

## 取值说明

| 值 | 含义 | 说明 |
|----|------|------|
| `0` | 未确认 / 接收消息 | 96.03%；所有 40013=0/3 消息均为此值 |
| `1` | 已读 / 已送达（推测） | 3.97%；仅出现于 40013=1/2（发送方向） |

## 取值分布

| 值 | 行数 | 占比 |
|----|------|------|
| `0` | 1,266,268 | 96.03% |
| `1` | 52,320 | 3.97% |

## 与 40013（消息方向）交叉

| 方向 | 40105=0 | 40105=1 |
|------|---------|---------|
| 0 (recv) | 632,576 | **0** |
| 1 (sent) | 620,863 | 21,373 |
| 2 (sent_special) | 12,545 | 30,947（占该方向 71.2%） |
| 3 (system) | 40 | **0** |

- **接收消息中 40105 从不为 1**，说明该标志仅属于发送侧语义
- `sent_special`（跨设备同步消息）中 71% 为 `1`，可能因同步消息天然携带已确认状态

## 时间分布（40105=1，按月）

2024-10 起开始出现，此后持续分布至 2026-05，无明显集中区间，非一次性事件。

## 关联字段

| 字段 | 关系 |
|------|------|
| `40013` | 强关联：40105=1 仅出现于 40013∈{1,2}（发送方向） |
| `40011` | 弱关联：40105=1 时以类型 2 为主，与类型分布比例一致 |

## 验证方法

- 在 QQ 中向对方发送消息后查看该字段变化（送达前后对比）
- 对比消息体（40800）的 protobuf 结构是否包含已读回执标志位

## 说明

- 置信度低：虽然方向关联显著，但"已读"和"已送达"两种假设均符合数据，且接收消息恒为 0 亦可能只是协议规范而非语义约束
- `sent_special` 方向的高比例（71.2%）仍待解释
