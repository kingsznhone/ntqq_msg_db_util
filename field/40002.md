# 字段 `40002` — 消息随机数

| 属性 | 值 |
|------|-----|
| 字段编号 | 40002 |
| 类型 | INTEGER |
| 所属表 | c2c_msg_table |
| 置信度 | 🔍 中（基于 131 万行统计验证，符合随机数生日悖论碰撞预期） |

## 含义

**消息随机数（msgRandom）**：客户端发送消息时随机生成的整数，用于服务端去重和 ACK 匹配。对应经典 QQ 协议中的 `msgRandom` 字段。

| 特征 | 结果 |

| 不重复值数 | 1,303,292（重复数 15,296，重复率 1.16%） |
| 值域 | `0` ～ `9,053,996,380,769,368,925` |

| 与 40001 相关性 | Pearson = 0.099（独立） |
| 高 32 位唯一性 | 前 10000 行高位仅 1 种（绝大多数值为 32-bit 整数，高 32 位为 0） |

## 说明

- **重复是正常碰撞**：131 万条消息中有约 1.5 万个重复值，符合 32-bit 随机数的生日悖论预期（空间 2³²，131 万次约 0.02% 碰撞概率）。重复值出现在不同会话、不同时间，无语义关联。
- **极少数超大值**：最大值约 9×10¹⁸，高于 2³² 上限，来自 NT 新协议将随机数空间扩展为 64-bit。
- **值为 0 的 30 条**：均对应时间戳异常（1970 / 2011 年），是旧版 QQ 数据迁移的占位记录，非正常消息。
- **不能作为唯一标识**：与 40001（严格唯一主键）搭配才能唯一定位一条消息。
- **跨会话重复**：13,203 个值跨越多个会话，属于自然碰撞，不代表语义关联。
