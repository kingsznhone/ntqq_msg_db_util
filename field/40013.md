# 字段 `40013` — 消息发送方向

| 属性 | 值 |
|------|-----|
| 字段编号 | 40013 |
| 类型 | INTEGER |
| 所属表 | c2c_msg_table |
| 置信度 | ✅ 高（基于 130 万行统计验证） |

## 含义

**消息发送方向标志**：标识该条消息是由本人发出还是由对方发来。

## 取值说明

| 值 | 含义 | 说明 |
|----|------|------|
| `0` | **对方发送（收到）** | 发送者 QQ（40033）与私聊对象（40030）一致，为收到的消息 |
| `1` | **自己发送** | 发送者 QQ（40033）为本人，正常发出的消息 |
| `2` | **自己发送（特殊类型）** | 发送者同为本人，具体与 `1` 的区别尚待结合 `40012` 进一步分析 |
| `3` | **系统消息 / 通知** | 40033 与 40030 均为 `0`，无实际 QQ 号，配合 `40012=12/17` 出现 |
| `4` | **自发消息特殊状态** | 发送者为本人，疑似撤回或发送失败，数量极少（＜50 条） |
| `5` | **自发消息特殊状态** | 发送者为本人，`40012` 全为 `7`，数量极少（＜60 条），含义待确认 |
| 大整数（如 `1367366400`） | **旧版迁移噪音** | 值均为整日 Unix 时间戳（2013～2022 年），与 `40058` 字段含义重叠，系旧版 QQ 数据迁移时写入错误，可忽略 |

## 取值分布（共 1,318,588 行）

| 值 | 行数 | 占比 |
|----|------|------|
| `1`（自己发送）| 642,236 | 48.71% |
| `0`（对方发送）| 632,576 | 47.97% |
| `2`（自发特殊）| 43,492 | 3.30% |
| 其他（噪音 + 系统）| 226 | 0.02% |

## 验证方法

- **`0`（对方发送）**：`40033 == 40030` 吻合率 99.77%
- **`1`（自己发送）**：`40033` 高度集中于本人 QQ，与所有会话的 `40030` 均不同
- **`2`（自发特殊）**：`40033` 同为本人 QQ，`40033 != 40030` 占比 100%

## 关联字段

| 字段 | 关系 |
|------|------|
| `40033` | 发送者 QQ，与 `40013` 联合可确认消息方向 |
| `40030` | 私聊对象 QQ，`40013=0` 时与 `40033` 相等 |
| `40012` | 消息标志位，与 `40013=2/3/4/5` 配合可进一步分类 |
