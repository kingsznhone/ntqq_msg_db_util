# 字段 `40012` — 消息属性标志位

| 属性 | 值 |
|------|-----|
| 字段编号 | 40012 |
| 类型 | INTEGER |
| 所属表 | c2c_msg_table |
| 置信度 | ✅ 高（bit0/bit1/bit12 全量 130 万行 protobuf 验证通过；bit4 基于统计推测；其他 `40011` 绑定值全量确认） |

## 含义

**消息属性标志位（Message Flag Bitmask）**：在 `40011=2`（标准消息）时为真正的位掩码，各 bit 独立叠加；对于其他 `40011` 值，该字段通常固定为某一特定值，语义偏向"内容子状态"。

## 位掩码定义（仅在 `40011=2` 时有效）

> 📌 `40800.md` 注：`40012` 与 `MsgContent.content_type`（字段 45002）存在对应关系，各 bit 可能编码了该消息包含哪些 content_type 子类型，具体映射规则待逐类型 protobuf 验证。

| Bit | 掩码值 | 出现率 | 含义 | 置信度 |
|-----|--------|--------|------|--------|
| bit0 | `0x0001` (1) | 81.1% | **含文本内容**（对应 content_type=1）：精确率 100%（置位时 ct=1 必在）、召回率 99.97%（361 FN 全为 `40012=0x0000` 的边缘消息）；置位时消息体平均 55B | ✅ 高 |
| bit1 | `0x0002` (2) | 20.6% | **含富媒体内容**（对应 content_type=2，图片/表情等）：精确率 100%（置位时 ct=2 必在）、召回率 93.9%；**例外：`40012=0x1000`（长消息/合并转发）含 ct=2 时不设 bit1**（17,662 FN 全为此情形）；置位时消息体平均 ~200B | ✅ 高 |
| bit4 | `0x0010` (16) | 1.74% | **撤回 / 状态变更通知**，消息体极小（平均 30B），通常不含 bit0 | 🔍 中 |
| bit12 | `0x1000` (4096) | 1.34% | **长消息 / 合并转发**，消息体显著变大（平均 948B）；仅在 `40011=2` 下出现（全量验证）；含 ct=2 时**不同时**设 bit1 | ✅ 高 |

> 其余 bit（bit2/3/5/7/9/11/15）出现率极低（＜0.2%），含义待 protobuf 解析确认。
