# 字段 `40012` — 消息属性标志位

| 属性 | 值 |
|------|-----|
| 字段编号 | 40012 |
| 类型 | INTEGER |
| 所属表 | c2c_msg_table |
| 置信度 | 🔍 中（基于取值分布、位分析及消息体大小关联推测） |

## 含义

**消息属性标志位（Message Flag Bitmask）**：在 `40011=2`（标准消息）时为真正的位掩码，各 bit 独立叠加；对于其他 `40011` 值，该字段通常固定为某一特定值，语义偏向"内容子状态"。

## 位掩码定义（仅在 `40011=2` 时有效）

| Bit | 掩码值 | 出现率 | 推测含义 |
|-----|--------|--------|---------|
| bit0 | `0x0001` (1) | 81.1% | **基础消息标志**，绝大多数普通消息置位 |
| bit1 | `0x0002` (2) | 20.6% | **富媒体内容**（图片、表情包、文件缩略图等），置位时消息体平均从 55B 增至 ~200B |
| bit4 | `0x0010` (16) | 1.74% | **撤回 / 状态变更通知**，消息体极小（平均 30B），通常不含 bit0 |
| bit12 | `0x1000` (4096) | 1.34% | **长消息 / 合并转发**，消息体显著变大（平均 948B），仅在 `40011=2` 下出现 |

> 其余 bit（bit2/3/5/7/9/11/15）出现率极低（＜0.2%），含义待 protobuf 解析确认。

## 常见组合解读（`40011=2`）

| 40012 值 | 二进制 | 推测含义 | 消息体均值 |
|---------|--------|---------|-----------|
| `1` | `0000 0001` | 纯文本消息 | 55B |
| `2` | `0000 0010` | 富媒体消息（图片/表情） | 204B |
| `3` | `0000 0011` | 图文混排（文字+图片） | 223B |
| `16` | `0001 0000` | 撤回通知 | 30B |
| `17` | `0001 0001` | 带回执标记的文本 | 78B |
| `33` | `0010 0001` | 引用回复消息 | 278B |
| `4096` | `1000 0000 0000` | 合并转发 / 长消息 | 948B |
| `4097` | `1000 0000 0001` | 超长合并转发 | 1384B |

## 与 `40011` 的绑定关系（`40011≠2` 时）

| 40011 | 40012 固定值 | 绑定率 | 含义 |
|-------|------------|--------|------|
| `6`（名片） | `0x0000` | 100% | 无附加标志 |
| `7`（位置） | `0x0000` | 100% | 无附加标志 |
| `8`（语音） | `0x0000` | 100% | 无附加标志 |
| `9`（Reaction） | `0x0021` | 99.3% | bit0+bit5 固定组合 |
| `10`（通话） | `0x0000` | 100% | 无附加标志 |
| `17`（状态通知） | `0x0008` | 100% | bit3 固定 |

## 关联字段

| 字段 | 关系 |
