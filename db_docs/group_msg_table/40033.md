# 字段 `40033` — 发送者 QQ

| 属性 | 值 |
|------|-----|
| 字段编号 | 40033 |
| 类型 | INTEGER |
| 所属表 | `group_msg_table` |
| 置信度 | ✅ 高 |

## 含义

`40033` 是实际发送该条群消息的 QQ 号。群聊中同一个 `40030` 会对应多个不同的 `40033`，分别代表不同群成员；系统消息或特殊记录可能使用 `0`。

## 统计证据

基于 `540,018` 行群消息：

- `40033=0`：3,994 行；
- 其中同时 `40030=0`：3,977 行；
- 非零群号下，同一群出现多个不同发送者，最多的群组统计到数百个发送者；
- `40013=1/2` 的发送方向记录中，发送者 QQ 与会话内本人候选一致率均为 100%；
- `40013=3` 的系统消息记录中，`40033=0` 全部成立。

## 取值规则

| 场景 | `40033` 解释 | 置信度 |
|------|--------------|--------|
| 普通群成员消息 | 实际发送者 QQ | ✅ 高 |
| 本人发送消息 | 本人 QQ | ✅ 高 |
| 系统消息/群动作 | 通常为 0 | ✅ 高 |
| 历史迁移或异常记录 | 可能为 0 或缺失 | 🔍 中 |

## 关联字段

| 字段 | 关系 |
|------|------|
| `40030` | 群号；同一群对应多个发送者 |
| `40020` | 发送者 NT UID，与发送者身份对应 |
| `40013` | 发送/来源标志；可区分本人、他人和系统消息 |
| `40093` | 发送者昵称或群昵称 |
| `40003` | 发送者所在群内消息序号 |

## 结论

`40033` 是发送者 QQ 号，置信度为 **✅ 高**。对普通群消息可直接作为发送者标识；对 `40030=0` 或系统消息记录，应按特殊记录处理。

## 使用边界

- `40033` 是实际发送者 QQ；系统消息通常为 0。
- 与 `40013`、`40020` 联合判断发送者来源。
