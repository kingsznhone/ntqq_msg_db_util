# 字段 `40040` — NT 同步/消息来源流程标志

| 属性 | 值 |
|------|-----|
| 字段编号 | 40040 |
| 类型 | INTEGER |
| 所属表 | `group_msg_table` |
| 置信度 | 🔍 中 |

## 含义

`40040` 是与 NT 协议同步或消息来源流程相关的标志字段。当前统计支持以下暂定解释：

- `0`：普通默认路径；
- `1`：特殊 NT 路径，常见于本人发送、特殊发送或协议事件。

目前尚不能仅凭数据库确认 `40040=1` 是否严格等于多端同步，也不能排除服务端回写、发送流程确认或其他 NT 内部事件。

## 取值分布

基于 `540,018` 行群消息：

| 值 | 行数 | 占比 | 当前解释 |
|---:|-----:|-----:|----------|
| `0` | 535,549 | 99.17% | 普通默认路径 |
| `1` | 4,469 | 0.83% | 特殊 NT 同步/来源流程 |

## 交叉验证

### 与 `40013` 的关系

`40040=1` 中：

- `40013=2`：3,158 行，占 70.66%；
- `40013=1`：1,291 行，占 28.89%；
- `40013=0`：13 行；
- `40013=4/5`：7 行。

这说明非零值高度集中于本人发送和特殊发送路径，但并非完全限定于这些方向。

### 与 `40041` 的关系

- `40040=0` 的记录全部为 `40041=2`；
- `40040=1` 中 99.93% 为 `40041=2`；
- 仅 3 条 `40040=1` 记录为其他状态。

因此，`40040` 不是发送成功/失败状态字段。

### 与 `40009` 的关系

`40040=0` 和 `40040=1` 中 `40009=1` 的比例都约为 99.3%，两字段不是一一对应关系，因此 `40040` 不是批量转发标志。

### 与 `40105` 的关系

`40040=1` 中 `40105=1` 的比例为 72.41%，但仍有 1,233 条记录为 `40105=0`；二者不等价。因此 `40040` 也不是已读或送达标志。

## 解释边界

- `40040=1` 与 NT 新协议特殊消息、本人发送和特殊发送方向高度相关；
- `40040=0` 是绝大多数消息的默认值，不能简单断言为“本机自然产生”；
- “多端同步”是目前最合理但尚未直接抓包验证的具体解释。

## 关联字段

| 字段 | 关系 |
|------|------|
| `40013` | 非零 `40040` 主要集中于本人发送或特殊来源方向 |
| `40041` | 发送状态；与 `40040` 不等价 |
| `40009` | 批量/转发标志；与 `40040` 无一一对应关系 |
| `40105` | 发送侧确认/回执相关字段；与 `40040` 部分相关但不等价 |
| `40011` | 特殊消息类型在 `40040=1` 中占比更高 |

## 结论

`40040` 是 NT 同步/消息来源流程标志，字段总体置信度为 **🔍 中**。`40040=1` 的具体“多端同步”语义仍需跨设备样本、原始数据库或网络抓包进一步确认。

## 使用边界

- `40040=1` 只能作为来源/同步路径提示，不能直接解释为跨设备同步或已读。
