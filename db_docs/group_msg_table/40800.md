## group 表结论

`40800` 存储群消息的实际内容主体，采用与 C2C 同源的 Protobuf 模型。文本、图片、文件、语音、视频、回复、合并转发、系统通知和通话等内容均序列化在该字段中。

## 共享模型验证

group 与 C2C 的 `40800` 具有相同的核心 Protobuf 模型：

- 外层 `MsgBody.content = 40800` repeated；
- 内层 `MsgContent`；
- 通用字段 `45001/45002/45003`；
- 文本字段 `45101`；
- 媒体、CDN、回复、转发、系统和通话字段区段编号一致；
- 递归消息和 repeated 字段的 wire 结构兼容。

共享 canonical schema 位于：

- `msgdb/proto/40800.proto`
- `msgdb/proto/c2c_40800.proto`
- `msgdb/proto/c2c_40800_pb2.py`

表级入口仍然分开：

- `msgdb.c2c.parser`：C2C 元数据、内容模型和导出；
- `msgdb.group.parser`：group 元数据和 group wire fallback。
