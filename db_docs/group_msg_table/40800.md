# 字段 `40800` — 群消息体（共享 Protobuf）
 
> 通用字段定义和解析规则统一维护于 [`c2c_msg_table/40800.md`](../c2c_msg_table/40800.md)。本页只记录 group 表的验证结果和与 C2C 不同的解释边界。

## 结论

`group_msg_table.40800` 存储群消息正文及内容元数据，使用与 C2C 相同的：

```text
MsgBody.content = 40800 (repeated MsgContent)
```

group 与 C2C 共用 `msgdb/proto/c2c_40800.proto`，不维护第二套完整消息体 schema。

## group 快照统计

解析器仍保留 `wire_fallback`，用于未来遇到新版本字段时无损保留原始 wire 数据。

## group 特有验证

### `45101` 文本

group 中 `45101` 的非空段共 `467,470` 个，全部通过 UTF-8 解码。读取时可沿用 C2C 规则：按原始 bytes 解码为应用层文本，不要将偶发的 wire-like 字节误判为嵌套 Protobuf。

### `45001` 段级 ID

group 中观察到 `633,995` 个 `45001` 值：

- 不等于所在行主键 `40001`；
- distinct 值 `633,992`；
- 按数据库顺序非递减 `631,497 / 633,994`，约 `99.61%`；
- 只能作为 `MsgContent` 段级 ID 使用，不能替代主表消息 ID。

### group 引用字段

group 回复样本支持以下共享字段解释，但这些统计不应无条件推广到没有对应场景的 C2C 记录：

| 字段 | group 观察 |
|---:|---|
| `47402` | 与同一会话的 `40003` 群内消息序号高度匹配，适合作为回复目标序号读取 |
| `47404` | 值域符合 Unix 秒级时间戳，支持被引用消息发送时间解释 |
| `47413` | 少量样本为可读文本，支持引用摘要解释 |
| `47421` | 少量样本为显示文本/群昵称 |
| `47422` | 未与主表 `40001` 匹配，暂作内部来源 ID |

### group 视频和文件字段

- `45422`：视频分支中的预览封面文件名/路径；
- `45862`：视频预览封面 MD5；
- `45954`：文件分支中的预览封面路径。

这三个结论均来自 group 样本中的稳定场景关联，具体字段速查见共享 `40800` 文档。

## 边界

- group 的 `40800` 与 C2C 同源，但表级字段 `40011`、`40012`、`40850` 的场景解释仍以 group 详情页为准。
- `45001` 是段级 ID，不是 `40001` 的别名。
- 解析成功表示结构可读取，不代表所有内部字段的业务语义都已命名。
