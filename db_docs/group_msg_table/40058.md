# 字段 `40058` — 日期索引

| 属性 | 值 |
|------|-----|
| 字段编号 | 40058 |
| 类型 | INTEGER |
| 所属表 | `group_msg_table` |
| 置信度 | ✅ 高 |

## 含义

`40058` 是消息日期索引，存储该消息所在日期 **UTC+8 00:00:00** 对应的 Unix 秒级时间戳。

它不是消息的精确发送时间；精确时间由 `40050` 提供。`40058` 适合用于按日期分区、索引和快速筛选。

## 全量验证

基于 `540,018` 行群消息：

- 可比较行数：`539,988`；
- `40050<=0`：17 行；
- `40058<=0`：13 行；
- 日期零点完全一致：`539,988 / 539,988`；
- 一致率：`100.0000%`；
- `40058` 每个取值均对应唯一日期：`71 / 71`；
- `40050 - 40058` 的有效偏移全部位于当天 `0~86,399` 秒范围内。

## 验证方法

对每条可比较记录：

1. 将 `40050` 作为 Unix 秒级时间戳转换为 UTC+8 本地日期；
2. 计算该日期 UTC+8 00:00:00 的 Unix 时间戳；
3. 与 `40058` 比较。

所有可比较记录均精确相等，没有发现群号、会话或特殊方向导致的系统性偏差。

## 使用边界

- `40058` 只能表示日期，不能代替 `40050` 的时分秒信息；
- 非正值应视为无效或特殊记录；
- 应按 UTC+8 解释，不能直接按 UTC 日期零点解释；
- 同一天的所有消息共享同一个 `40058` 值。

## 关联字段

| 字段 | 关系 |
|------|------|
| `40050` | 精确消息发送时间；两者差值为当天经过的秒数 |
| `40003` | 群内消息序号；可结合日期索引进行日期内排序分析 |
| `40027` | 本地会话键；数据库索引中常与日期索引联合使用 |
| `40030` | 群号；可按群号和日期索引筛选消息 |

## 结论

`40058` 是 UTC+8 当日 00:00:00 的 Unix 秒级日期索引，置信度为 **✅ 高**。
