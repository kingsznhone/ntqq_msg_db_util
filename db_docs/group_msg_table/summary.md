# `group_msg_table` 字段速查
> 数据源：`nt_msg_plain.db` / `group_msg_table`，本页统计基线为 `540,018` 行。数字是该数据库快照的统计结果，不代表所有 QQ/NTQQ 版本。
>
> 置信度：✅ 已验证；🔍 当前数据支持的解释；❓ 仅确认结构或样本不足；未知：没有可靠语义。

## 使用入口

- 判断群、发送者和方向：使用 `40027`、`40030`、`40033`、`40013`。
- 读取消息正文和媒体内容：使用共享 [`40800.md`](40800.md)，内部字段见 [`../c2c_msg_table/40800.md`](../c2c_msg_table/40800.md)。
- 处理群回复：使用 `40850`；它与 C2C 的 Reaction 关联字段含义不同。
- 处理群 Reaction：联合读取 `40062`、`40083`、`40084` 和 `40900`。
- 解析附加结构：使用 `40600`、`40605`、`40801`、`40900` 对应的 group 专用 parser。
