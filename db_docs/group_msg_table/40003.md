# 字段 `40003` — 群内消息序号

| 属性 | 值 |
|------|-----|
| 字段编号 | 40003 |
| 类型 | INTEGER |
| 所属表 | `group_msg_table` |
| 置信度 | ✅ 高 |

## 含义

`40003` 是群聊范围内的消息序号。对于同一个群号 `40030`，按发送时间 `40050` 排序时，该字段稳定非递减，通常严格递增；但相同序号可以在不同群之间复用，因此它不是全局唯一 ID。

## 统计证据

基于 `540,018` 行群消息：

| 指标 | 结果 |
|------|------:|
| 非零 distinct 值 | 478,756 |
| 按非零群号分组、按 `40050` 排序的非递减比例 | 100.00% |
| 按 `40027` 分组、按 `40050` 排序的非递减比例 | 100.00% |
| 按非零群号分组的严格递增比较 | 534,696 / 534,696 |
| 可跨多个群复用的序号分组 | 56,459 |

全表直接按时间排序时只有 73.25% 非递减，这是因为多个群的序号空间相互独立，跨群交错后不能要求全局单调。

## 取值特征

- 同一群内，序号随发送时间向后推进；
- 同一序号可出现在多个群中；
- 不应使用 `40003` 作为表的唯一主键；
- `40001` 才是消息记录的主键。

## 关联字段

| 字段 | 关系 |
|------|------|
| `40030` | 群号；`40003` 的序号空间按群隔离 |
| `40027` | 本地会话键；与群号存在稳定对应关系 |
| `40050` | 发送时间戳；用于验证群内序号的时序方向 |
| `40001` | 消息唯一 ID；用于唯一定位记录 |
| `40013` | 方向/来源标志；不改变群内序号的基本排序关系 |

## 结论

`40003` 的字段语义为**群内消息序号**，置信度为 **✅ 高**。它具有群内时序性，但不是全局唯一序号，也不能跨群直接比较大小。
