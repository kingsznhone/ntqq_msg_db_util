# 字段 `40090` — 发送者群名片

| 属性 | 值 |
|------|-----|
| 字段编号 | 40090 |
| 类型 | TEXT |
| 所属表 | `group_msg_table` |
| 置信度 | ✅ 高 |

## 含义

`40090` 是群消息中的发送者显示名称字段，表示发送者的**群名片**。它通常与 `40093` 的默认昵称回退互补。

外部资料对该字段的说明采信度较高，并补充了旧版 QQ 的格式：

- `name(12345)`
- `name<i@example.com>`

这些格式可能把昵称与 QQ 号或邮箱样式标识拼接在一起。它们应作为旧版消息记录的兼容格式处理；当前 NT 数据中则按群名片解释。

## 与 `40093` 的关系

- `40090` 非空时，优先解释为群名片/群昵称；
- `40090` 为空或未设置群名片时，`40093` 可能提供默认昵称；
- 两者的互斥关系和具体回退优先级仍以当前数据库统计为准。

## 结论

`40090` 是发送者群名片字段，置信度为 **✅ 高**。旧版 `name(12345)` 和 `name<i@example.com>` 是兼容旧消息记录的显示格式，不改变字段的主体语义。
