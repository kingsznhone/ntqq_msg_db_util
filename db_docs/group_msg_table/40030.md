# 字段 `40030` — 群号

| 属性 | 值 |
|------|-----|
| 字段编号 | 40030 |
| 类型 | INTEGER |
| 所属表 | `group_msg_table` |
| 置信度 | ✅ 高 |

## 含义

`40030` 是群聊消息所属的群号。非零值用于标识实际群聊，会话键 `40027` 与其具有稳定对应关系；`40030=0` 主要出现在系统消息、特殊记录或异常迁移记录中。

## 统计证据

基于 `540,018` 行群消息：

- 非零群号值：30 个；
- 包含 0 在内的值：31 个；
- 非零群号消息：534,743 行；
- `40030=0`：5,275 行；
- `(40027,40030)` 组合数：59；
- 主要会话中，一个 `40027` 对应一个非零群号，同时可能附带 `40030=0` 的特殊记录。

同一非零群号下存在多个不同 `40033`，符合群聊中多成员发送消息的结构。

## `40030=0` 的解释边界

不能将所有 `40030=0` 都直接等同于损坏数据。它主要与以下情况相关：

- 系统消息或群动作消息；
- 没有普通群成员发送者的特殊记录；
- 少量历史迁移或字段缺失记录。

应结合 `40013`、`40033`、`40011` 和 `40012` 联合判断。

## 关联字段

| 字段 | 关系 |
|------|------|
| `40027` | 本地会话键，与非零群号稳定对应 |
| `40033` | 实际发送者 QQ；同一群可有多个发送者 |
| `40003` | 群内消息序号；序号空间按群隔离 |
| `40050` | 消息发送时间 |
| `40013` | 系统消息方向中常见 `40030=0` |

## 结论

`40030` 是群号，置信度为 **✅ 高**。非零值是群聊标识；零值属于系统/特殊/异常记录，应结合其他字段解释。

## 使用边界

- `40030` 是群号；系统消息或特殊记录中的 0 不代表真实群号。
