# 字段 `40001` — 消息唯一 ID

| 属性 | 值 |
|------|-----|
| 字段编号 | 40001 |
| 类型 | INTEGER |
| 所属表 | `group_msg_table` |
| 主键 | 是 |
| 置信度 | ✅ 高 |

## 含义

`40001` 是群消息表的消息唯一 ID，同时也是 SQLite 表的主键。它负责在数据库中唯一定位一条消息记录，不应与群内序号 `40003` 或消息随机数 `40002` 混用。

## 统计证据

基于 `540,018` 行群消息：

- distinct 值：`540,018`；
- 重复行：`0`；
- 所有记录均有唯一的 `40001`；
- 所有值均为 63 bit 整数；
- 按 `40050` 时间升序排列时，`40001` 非递减比例为 `99.04%`；
- 按群号分组、再按 `40050` 排序时，`40001` 非递减比例为 `99.71%`。

这说明它具有近似生成时间顺序，但跨群消息交错、批量写入和时间戳相同等情况会造成少量逆序，不能把它直接当作严格时间戳。

## 取值特征

- 低 4 bit 的 16 种取值分布接近均匀；
- 没有发现明显的低位时间编码或固定步长模式；
- 消息 ID 与发送时间具有顺序相关性，但 ID 本身不等于 Unix 时间戳；
- 与 `40003` 不同，`40001` 全表唯一，适合作为消息记录主键。

## 与其他字段的区别

| 字段 | 角色 | 是否唯一 |
|------|------|----------|
| `40001` | 数据库消息唯一 ID | 是 |
| `40002` | 消息随机数/去重随机值 | 否，存在少量碰撞 |
| `40003` | 群内消息序号 | 否，可跨群复用 |
| `40050` | Unix 秒级发送时间戳 | 否，同秒可有多条消息 |

## 关联字段

| 字段 | 关系 |
|------|------|
| `40002` | 与消息记录共同构成客户端/协议层消息标识信息，但随机数不具备唯一性 |
| `40003` | 群内顺序字段，不可替代 `40001` |
| `40030` | 群号；群内消息按时间与 `40001` 联合排序 |
| `40050` | 消息发送时间；`40001` 通常随时间增长 |

## 结论

`40001` 是消息唯一 ID，也是 `group_msg_table` 的主键，置信度为 **✅ 高**。它具有近似时间递增特征，但不应被解释为时间戳或群内序号。
