# 字段 `40020` — 发送者 NT UID

| 属性 | 值 |
|------|-----|
| 字段编号 | 40020 |
| 类型 | TEXT |
| 所属表 | `group_msg_table` |
| 置信度 | ✅ 高 |

## 含义

`40020` 是实际发送该条群消息的用户 NT UID。它是发送者身份字段，与 `40033`（发送者 QQ）存在稳定的一对一映射关系。

## 格式与统计

基于 `540,018` 行群消息：

- distinct：`2,637`；
- 标准 `u_` + 22 个 Base64url 字符格式：`536,107` 行；
- 非标准格式：`3,911` 行，主要为空字符串及少量历史/系统值；
- 标准格式总长度为 24 字符。

## 与 `40033` 的映射

在 `40033` 非零的记录中：

- UID → QQ 的一对一比例：`2,623 / 2,623`；
- QQ → UID 的一对一比例：`2,623 / 2,623`。

因此，`40020` 与 `40033` 均可用于表达发送者身份，但 NT UID 更适合在 NT 协议上下文中作为稳定身份键。

## 与方向字段的关系

| `40013` | `40020` 特征 | 解释 |
|---:|----------|------|
| `0` | 绝大多数为标准 UID | 他人发送的群成员消息 |
| `1` | 全部为标准 UID | 本人正常发送 |
| `2` | 全部为标准 UID | 本人发送的特殊类型 |
| `3` | 全部为非标准 UID | 系统消息或无普通用户发送者 |
| `4/5` | 标准 UID | 极少量特殊发送记录 |

在 `40013=1/2` 的发送方向中，没有发现 `40020=40021`；群聊中 `40021` 更可能表示会话/群对象 UID，而不是实际发送者 UID。

## 与群聊的关系

- 同一群可以出现大量不同的 `40020`，对应不同群成员；
- 最大群组中观察到 437 个不同发送者 UID；
- 不同 `40011` 消息类型均可出现发送者 UID；
- 系统消息和历史异常记录可能使用空字符串或非标准值。

## 关联字段

| 字段 | 关系 |
|------|------|
| `40033` | 发送者 QQ；与 `40020` 一对一对应 |
| `40013` | 发送/来源标志；辅助判断本人、他人和系统消息 |
| `40021` | 会话/群对象 UID；通常不等于群成员发送者 UID |
| `40030` | 群号；同一群对应多个发送者 UID |
| `40093` | 发送者昵称或群昵称 |

## 结论

`40020` 是发送者 NT UID，置信度为 **✅ 高**。非标准值属于系统、历史或字段缺失记录，不影响主体语义。

## 使用边界

- 正常记录中使用 `40020` 读取实际发送者 NT UID，并与 `40033` 联合校验。
- 少量异常或迁移记录可能没有标准 UID，不应据此否定字段主语义。
