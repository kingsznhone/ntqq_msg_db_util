# 字段 `40050` — 消息发送时间戳

| 属性 | 值 |
|------|-----|
| 字段编号 | 40050 |
| 类型 | INTEGER |
| 所属表 | `group_msg_table` |
| 置信度 | ✅ 高 |

## 含义

`40050` 是消息发送时间的 Unix 时间戳，单位为秒。实际日期显示通常按 UTC+8 解释。

## 统计证据

基于 `540,018` 行群消息：

- 非正时间戳：17 行；
- 其余记录均为有效秒级时间值；
- 数据时间范围覆盖当前数据库样本的消息保存周期；
- 按 UTC+8 将 `40050` 转为日期后，与 `40058` 的日期索引逐行比对，除无法比较的 30 行外，不一致数为 0。

## 与 `40058` 的关系

`40058` 是日期索引，即对应日期 UTC+8 00:00:00 的 Unix 时间戳。验证逻辑为：

1. 将 `40050` 按 UTC+8 转换为本地日期；
2. 计算该日期 UTC+8 零点的 Unix 秒值；
3. 与 `40058` 比较。

有效时间记录全部通过该日期一致性检查。

## 使用边界

- `40050` 是外层消息时间，不保证等于 protobuf 内层的所有时间字段；
- 批量消息、系统消息和迁移记录可能存在时间排序异常；
- 非正值应视为无效或缺失时间，不应直接转换为正常日期。

## 关联字段

| 字段 | 关系 |
|------|------|
| `40003` | 同一群内通常随 `40050` 递增 |
| `40058` | UTC+8 日期零点索引，与 `40050` 日期完全一致 |
| `40001` | 可作为同秒消息的稳定排序辅助键 |
| `40013` | 不同来源/方向消息均使用该外层时间字段 |

## 结论

`40050` 是 Unix 秒级消息发送时间戳，按 UTC+8 解释，置信度为 **✅ 高**。

## 使用边界

- `40050` 是消息时间排序的主要字段，但批量、系统和迁移记录可能有局部顺序异常。
