# 字段 `40011` — 群消息外层类型

| 属性 | 值 |
|------|-----|
| 字段编号 | 40011 |
| 类型 | INTEGER |
| 所属表 | `group_msg_table` |
| 置信度 | ✅ 高 |

## 含义

`40011` 是群消息的**外层消息类型字段**，用于区分消息所属的主要内容或交互类别。它与 `40800` 中的 protobuf 消息段结构存在稳定对应关系，但一个外层类型可能包含多个内部消息段类型，因此不应把它当作 protobuf `content_type` 的简单复制。

本报告基于 `nt_msg_plain.db` 中 `540,018` 行群消息，以及成功解析的 `506,749` 条 `40800` protobuf 记录。

## protobuf 验证

成功解析的 `40800` 消息段中，以下映射具有稳定证据：

| `40011` | 主导内部 `content_type` | 说明 |
|---:|---:|------|
| `2` | `1`、`2`、`6` | 标准消息允许多种内容段和混合消息 |
| `3` | `3` | 文件消息 |
| `5` | `8` | 系统/灰字类消息 |
| `6` | `4` | 语音消息 |
| `7` | `5` | 视频消息 |
| `8` | `16` | 旧协议合并转发 |
| `9` | `7` | 回复消息，同时可能带文本、图片或表情段 |
| `10` | `9` | 红包/钱包消息 |
| `11` | `10` | 合并转发 |
| `17` | `11` | 原创表情/表情包 |
| `19` | `21` | 通话通知 |

`40011=2` 和 `40011=9` 不是单一内部类型：标准消息和回复消息可以由多个 protobuf 段组成，这是类型设计而非字段失效。

## 关联字段

| 字段 | 关系 |
|------|------|
| `40012` | 在外层类型内部进一步表示子类型或属性组合；其语义受 `40011` 约束 |
| `40800` | 消息主体 protobuf；用于验证外层类型与具体消息段的对应关系 |
| `40013` | 消息发送/来源标志；可辅助区分部分系统和转发场景 |
| `40100` | @ 状态；可辅助识别回复或提醒类消息 |

## 结论

`40011` 的“群消息外层类型”定义得到全表取值分布、组合分布和 protobuf 结构的共同支持，置信度为 **✅ 高**。具体少量枚举值的产品展示名称仍可能随 QQ 版本变化，但字段的分类性质已经确认。

## 使用边界

- `40011` 是表级外层分类，不是 `45002` 的简单复制。
- 复杂消息应联合 `40012` 和 `40800` 的实际段类型读取。
