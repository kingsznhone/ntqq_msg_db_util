# 字段 `40850` — 被回复消息的群内序号

| 属性 | 值 |
|---|---|
| 字段编号 | `40850` |
| 类型 | INTEGER |
| 置信度 | 🔍 中 |

## 结论

在 group 表中，`40850` 是回复/引用消息指向的目标消息序号。非零值几乎都能在同一 `40027` 会话中匹配历史消息的 `40003`。

这与 C2C 的 `40850` 不同：

- C2C：主要关联被 Reaction 消息的 `40005`；
- group：主要关联被回复消息的 `40003`。

## 统计

- `40850=0`：约 `93.85%`；
- 非零：约 `33,219` 行；
- 非零值中约 `99.88%` 能在同一 `40027` 中匹配 `40003`；
- group 的 `40851` 全量为 0，不能套用 C2C 的 Reaction 时间语义。

## 查询目标消息

```sql
SELECT *
FROM group_msg_table
WHERE "40027" = :session_id
  AND "40003" = :replied_msg_seq
ORDER BY "40050";
```

必须同时限制 `40027` 或群号，因为 `40003` 可以跨群复用。

## 使用边界

- `40850=0` 表示无目标、未填充或当前消息类型不适用，不能进一步区分。
- 当前结论只适用于 group 表，不覆盖 C2C 的 `40850` 语义。
