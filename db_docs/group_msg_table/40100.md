# 字段 `40100` — @ / 回复提醒状态

| 属性 | 值 |
|---|---|
| 字段编号 | `40100` |
| 类型 | INTEGER |
| 置信度 | 🔍 中 |

## 结论

`40100` 是 @ 或回复提醒相关状态，不能简化为布尔值。当前 group 数据中 `0/2/6` 与普通消息、回复消息和提醒场景形成稳定分布；`1/3` 样本不足。

## 取值分布

| 值 | 行数 | 当前读取方式 |
|---:|---:|---|
| `0` | 497,425 | 默认状态；通常没有可识别的提醒 |
| `2` | 42,153 | 他人/其他目标相关提醒状态 |
| `6` | 324 | 与“提醒当前用户”或回复提醒相容 |
| `1` | 111 | 未知状态 |
| `3` | 5 | 未知状态 |

`40100=2` 主要出现在 `40011=9` 回复消息，`40100=6` 也集中于回复相关记录。

## 使用边界

- `0/2/6` 的产品命名仍需结合正文中的实际 @ 目标验证；当前只按提醒状态读取。
- 不把 `40100` 直接等同于 `40600` 或 `40850`；它们分别是状态附加结构和回复目标序号。
- `1/3` 不作业务判断。
