# 字段 `40006` — 服务端操作/元素标识

| 属性 | 值 |
|---|---|
| 字段编号 | `40006` |
| 类型 | INTEGER |
| 置信度 | 🔍 中 |

## 结论

`40006` 是 group 消息中的复合数值标识。当前数据支持其属于服务端操作、元素或批次标识一类，但不足以在这些产品名称之间做确定区分。

## 观察

- 非零值具有固定高位前缀和离散低位；
- 与 `40050` 没有可作为通用排序键的严格单调关系；
- 部分值可能在相关记录之间复用；
- 不能将它等同于 `40800` 内层的 `45001` 段级 ID，也不能直接套用 C2C 的 `40006` 解释。

## 使用边界

读取时保留原始整数和十六进制表示；在没有元素对象或操作事件对照的情况下，不要依赖 `elem id`、`serverSeq` 或批次 ID 的单一命名。
