# 字段 `40801` — 群消息摘要/状态快照

## 结论

`40801` 是重复的摘要/状态快照 Protobuf，不是普通文本，也不是主表 `40001` 或 `40003` 的直接副本。group 专用 schema 能解析当前全部非 NULL 样本。

## 统计

基于 `540,018` 行：

- NULL：`4,014` 行；
- 非 NULL：`536,004` 行；
- 强类型解析成功：`536,004` 行；
- 成功率：`100%`。

## 结构

```text
Body.content = 40801 (repeated Content)
Content.41501 = 摘要条目标识
Content.41502 = 状态值
```

schema 和解析器：

- `msgdb/proto/group_40801.proto`
- `msgdb/proto/group_40801_parser.py`

## `41502` 分布

| 值 | 出现次数 | 主要外层类型 | 当前结论 |
|---:|---:|---|---|
| `2` | 534,728 | 普通消息、回复、文件、转发 | 默认状态 |
| `12` | 2,489 | 主要为 `40011=11` | 特殊状态 |
| `22` | 349 | 主要为 `40011=2` | 特殊状态 |

`41502=2` 覆盖多种消息类型，因此不能命名为某一种消息类型专属状态。

## `41501` 边界

当前样本中，`41501` 不直接等于所在行的 `40001`，也不直接等于 group 的 `40003`。因此只将其称为摘要条目标识或内部消息标识，不把它当作主表 ID 使用。

## 解析规则

- 优先使用 group 专用强类型 parser；
- 失败时回退到 `msgdb/proto/wire.py`；
- 保留未知字段和重复顺序；
- 不把 `41501/41502` 强行解释为已读、撤回、同步或发送状态。

## 研究边界

当前可以确定的是 Protobuf 结构、全量可解析性和状态分布；业务状态的产品命名仍需要更多版本或事件对照数据。
