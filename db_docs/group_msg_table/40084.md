# 字段 `40084` — 表态统计摘要候选

| 属性 | 值 |
|------|-----|
| 字段编号 | 40084 |
| 类型 | INTEGER |
| 所属表 | `group_msg_table` |
| 置信度 | 🔍 中 |

## 含义

`40084` 是与群消息表态/Reaction 状态相关的整数摘要字段。它与 `40062` 表态明细 BLOB、`40083` 统计字段几乎完全同步，但具体表示总表态数、某类表态数还是其他缓存值尚未确认。

## 统计证据

- `0`：`538,063` 行；
- 非零：`1,955` 行；
- 取值主要为 `1~6`，少量达到 `29`；
- 与 `40083` 相等：`540,015` 行；
- 与 `40083` 不相等：3 行；
- 与 `40062` 非 NULL 高度同步。

## 关联字段

| 字段 | 关系 |
|------|------|
| `40062` | 表态/Reaction 明细 BLOB |
| `40083` | 几乎完全同步的另一个表态统计字段 |
| `40011`、`40012` | 非零值覆盖普通消息、回复、视频、转发和状态类消息 |
| `40850` | 部分 Reaction/回复消息的关联序号 |

## 结论

`40084` 暂定为表态统计摘要字段，置信度为 **🔍 中**。具体数值含义暂不命名，也不能仅凭当前数据确定它与 `40083` 的分工。
