# 字段 `40083` — 表态统计摘要

| 属性 | 值 |
|------|-----|
| 字段编号 | 40083 |
| 类型 | INTEGER |
| 所属表 | `group_msg_table` |
| 置信度 | 🔍 中 |

## 含义

`40083` 是与群消息表态/Reaction 状态相关的整数摘要字段，表示该消息的表态表情数量总和。它与 `40062` 内各重复条目的 `48303` 数量相呼应，是便于统计而冗余存储的整型摘要值。

## 统计证据

- `0`：`538,063` 行；
- 非零：`1,955` 行；
- 取值主要为 `1~6`，少量达到 `23`；
- 与 `40084` 相等：`540,015` 行；
- 与 `40084` 不相等：3 行；
- 与 `40062` 非 NULL 高度同步。

## 关联字段

| 字段 | 关系 |
|------|------|
| `40062` | 表态/Reaction 明细 BLOB |
| `40084` | 几乎完全同步的另一个表态统计字段 |
| `40011`、`40012` | 非零值覆盖普通消息、回复、视频、转发和状态类消息 |
| `40850` | 部分 Reaction/回复消息的关联序号 |

## 结论

`40083` 可作为该消息的表态表情数量总和读取，置信度为 **🔍 中**。当前快照中它与 `40084` 几乎完全同步。

## 使用边界

- 该字段统计的是表态表情数量总和，不是单个表情的成员明细；单个表情的数量见 `40062` 内部字段 `48303`。
- 应与 `40062`、`40084` 联合读取。
