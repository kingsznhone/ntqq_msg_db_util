# 字段 `40083` — 表态统计摘要

| 属性 | 值 |
|------|-----|
| 字段编号 | 40083 |
| 类型 | INTEGER |
| 所属表 | `group_msg_table` |
| 置信度 | 🔍 中 |

## 含义

`40083` 是与群消息表态/Reaction 状态相关的整数摘要字段。当前数据支持它来自表态明细或同一 Reaction 状态，但不能确认其是否始终等于所有表情数量总和。

## 统计证据

- `0`：`538,063` 行；
- 非零：`1,955` 行；
- 取值主要为 `1~6`，少量达到 `23`；
- 与 `40084` 相等：`540,015` 行；
- 与 `40084` 不相等：3 行；
- 与 `40062` 非 NULL 高度同步。

## 关联字段

| 字段 | 关系 |
|------|------|
| `40062` | 表态/Reaction 明细 BLOB |
| `40084` | 几乎完全同步的另一个表态统计字段 |
| `40011`、`40012` | 非零值覆盖普通消息、回复、视频、转发和状态类消息 |
| `40850` | 部分 Reaction/回复消息的关联序号 |

## 结论

`40083` 可作为 Reaction 相关统计摘要读取，置信度为 **🔍 中**。具体统计维度未定。

## 使用边界

- 不把 `40083` 单独解释为完整的表态总数。
- 应与 `40062`、`40084` 联合读取。
