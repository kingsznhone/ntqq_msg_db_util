# 字段 `40013` — 群消息发送/来源标志

| 属性 | 值 |
|------|-----|
| 字段编号 | 40013 |
| 类型 | INTEGER |
| 所属表 | `group_msg_table` |
| 置信度 | ✅ 高 |

## 含义

`40013` 是群消息的**发送/来源标志**，用于区分收到的他人消息、本人发送的消息、系统消息以及少量特殊发送状态。

它不应仅被简化为二值“发送方向”：群消息表中存在 `0`、`1`、`2`、`3`、`4`、`5` 六种取值，其中 `3` 明确表现为系统消息，`2/4/5` 属于发送相关的特殊类型或状态。

本报告基于 `nt_msg_plain.db` 中 `group_msg_table` 的 `540,018` 行数据。

## 取值分布

| 值 | 行数 | 占比 | 当前解释 | 置信度 |
|---:|-----:|-----:|----------|--------|
| `0` | 531,837 | 98.49% | 收到的他人消息 | ✅ 高 |
| `1` | 1,291 | 0.24% | 本人正常发送的消息 | ✅ 高 |
| `2` | 3,161 | 0.59% | 本人发送的特殊类型/特殊来源消息 | 🔍 中 |
| `3` | 3,722 | 0.69% | 系统消息或群系统通知 | ✅ 高 |
| `4` | 1 | 极少 | 发送相关特殊状态 | ❓ 低 |
| `5` | 6 | 极少 | 发送相关特殊状态，可能与批量转发或同步流程有关 | ❓ 低 |

## 交叉验证

### 发送者字段

- `40013=0` 时，`40033` 非零占 99.95%；少数 `40033=0` 可能是历史迁移或系统边界记录。
- `40013=1` 时，全部记录的 `40033` 非零。
- `40013=2` 时，全部记录的 `40033` 非零。
- `40013=3` 时，全部 3,722 条记录的 `40033=0`，同时 `40030=0`，符合系统消息没有实际群成员发送者的特征。
- 在每个会话中以发送方向最常见的发送者作为“本人候选”后，`40013=1` 和 `40013=2` 的 `40033`、`40020` 一致率均为 100%。

### 消息类型

`40013` 与 `40011/40012` 存在明显聚类：

| 组合 | 行数 | 观察 |
|------|-----:|------|
| `40011=2, 40013=0` | 484,443 | 普通收到消息 |
| `40011=9, 40013=0` | 32,887 | 收到的回复消息 |
| `40011=5, 40012=12, 40013=3` | 3,012 | 系统/动作类消息 |
| `40011=5, 40012=8, 40013=3` | 653 | 系统/灰字类消息 |
| `40011=2, 40013=1` | 1,259 | 本人发送的标准消息 |
| `40011=2, 40013=2` | 3,034 | 本人发送的特殊标准消息 |

### 发送状态 `40041`

- `40013=0/2/3/4` 的记录全部为 `40041=2`。
- `40013=1` 中 99.92% 为 `40041=2`，另有 1 条为 `40041=3`。
- `40013=5` 仅 6 条，出现 `40041=2/3/0`，样本不足以推导具体状态语义。

`40041` 几乎恒为成功状态，因此只能作为辅助证据，不能单独定义 `40013`。

### 其他字段

- `40013=0` 时 `40009` 几乎恒为 `1`，但该现象不能单独说明 `40013` 的具体语义。
- `40105=1` 只出现在发送方向 `1/2`，进一步支持二者属于本人发送侧；其中 `40013=1` 占 77.46%，`40013=2` 占 70.80%。
- `40013=3/4/5` 均与 `40030=0` 全量或近全量相关，提示其与普通群成员消息不同。

## 取值解释边界

### `40013=0`

高置信度表示收到的他人消息。它覆盖群聊中的绝大多数普通消息，且发送者字段形态与群成员消息一致。

### `40013=1`

高置信度表示本人正常发送。发送者 QQ 和 NT UID 在会话内与发送侧本人候选 100% 一致。

### `40013=2`

确认属于本人发送侧，但与 `40013=1` 的产品级差异尚未完全确定。当前不将其强行命名为“同步”“特殊发送”或某一种具体消息类型。

### `40013=3`

高置信度表示系统消息/群系统通知：发送者 QQ 和群号均为 0，并集中于系统动作类 `40011=5` 组合。

### `40013=4/5`

样本量分别为 1 条和 6 条，只能确认是特殊方向/来源值，不能从当前数据库可靠区分批量转发、同步、撤回或发送流程状态。

## 关联字段

| 字段 | 关系 |
|------|------|
| `40033` | 实际发送者 QQ；与 `40013=1/2` 的本人候选一致 |
| `40020` | 实际发送者 NT UID；与发送方向的本人候选 UID 一致 |
| `40030` | 群号；系统消息中为 0 |
| `40011` | 外层消息类型；不同方向值在消息类型上有明显聚类 |
| `40012` | 子类型/属性组合；可辅助解释系统和特殊发送消息 |
| `40041` | 发送状态；作为辅助验证字段 |
| `40009` | 批量/同步相关标志；与少量特殊方向值有关联 |
| `40105` | 发送侧确认/送达相关字段；只在方向 `1/2` 中出现非零 |

## 结论

`40013` 的字段总体定义“群消息发送/来源标志”已得到发送者字段、会话内本人候选、群号、消息类型及状态字段的共同支持，置信度为 **✅ 高**。

其中：

- `0=收到的他人消息`：✅ 高；
- `1=本人正常发送`：✅ 高；
- `2=本人发送的特殊类型/特殊来源`：🔍 中；
- `3=系统消息/通知`：✅ 高；
- `4/5`：❓ 低，待后续样本或其他数据库验证。
