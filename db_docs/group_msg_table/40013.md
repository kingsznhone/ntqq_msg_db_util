# 字段 `40013` — 群消息发送/来源标志

| 属性 | 值 |
|---|---|
| 字段编号 | `40013` |
| 类型 | INTEGER |
| 置信度 | ✅ 高（字段总体定义） |

## 结论

`40013` 区分收到的他人消息、本人发送、系统消息和少量特殊来源。它不是简单的二值方向字段。

## 取值分布

| 值 | 行数 | 当前解释 | 置信度 |
|---:|---:|---|---|
| `0` | 531,837 | 收到的他人消息 | ✅ |
| `1` | 1,291 | 本人正常发送 | ✅ |
| `2` | 3,161 | 本人发送的特殊来源/类型 | 🔍 |
| `3` | 3,722 | 系统消息或群系统通知 | ✅ |
| `4` | 1 | 特殊来源 | ❓ |
| `5` | 6 | 特殊来源 | ❓ |

## 交叉规律

- `40013=0` 时，`40033` 几乎总是非零；`40013=3` 时 `40033` 和 `40030` 均为 0。
- `40013=1/2` 的发送者 QQ 和 NT UID 与会话内本人候选一致。
- `40013=1/2` 主要对应本人发送，`40013=3` 主要对应系统动作和通知。
- `40013=4/5` 样本太少，只能确认是特殊来源值。

## 使用边界

- `40013=2` 不强行命名为“其他客户端”；当前数据无法区分客户端来源、同步流程和其他特殊发送类型。
- `40013=4/5` 不命名为转发、撤回或发送失败，等待更多样本。
- 联合 `40033`、`40020`、`40030` 和 `40011/40012` 使用，不要只依赖单个方向值。
