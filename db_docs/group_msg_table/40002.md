# 字段 `40002` — 消息随机数

| 属性 | 值 |
|------|-----|
| 字段编号 | 40002 |
| 类型 | INTEGER |
| 所属表 | `group_msg_table` |
| 置信度 | ✅ 高 |

## 含义

`40002` 是消息附带的高基数随机数，适合作为消息去重、请求匹配或协议层辅助标识。它不是数据库唯一键，也不能替代 `40001`。

“随机数”这一字段定义得到高基数、近似均匀低位分布、缺乏时间单调性和少量碰撞等统计证据支持；其具体服务端 ACK 匹配用途属于协议层合理推测，当前数据无法直接观测确认。

## 统计证据

基于 `540,018` 行群消息：

- distinct 值：`539,784`；
- 重复造成的额外行：`234`；
- 发生重复的取值组：`135`；
- `40002=0`：100 行，占 `0.02%`；
- 与 `40050` 的 Pearson 相关系数：`-0.004573`；
- 按时间排序的相邻值没有稳定递增或递减趋势；
- 群内按时间排序后非递减比例约为 `50.56%`，接近无序随机基线。

## 取值特征

- 低 4 bit 的 16 种取值分布接近均匀；
- 绝大多数取值位长不超过 32 bit，符合客户端 32-bit 随机数的常见形态；
- 少量值超过 32 bit，可能来自协议扩展、历史迁移或不同生成路径；
- 重复主要表现为低频碰撞，不影响其作为随机辅助字段的判断；
- 100 个零值需要作为特殊/缺省值处理，不能视为随机生成结果。

## 与其他字段的区别

| 字段 | 角色 | 唯一性 |
|------|------|--------|
| `40001` | 数据库消息唯一 ID | 全表唯一 |
| `40002` | 消息随机数/去重随机值 | 存在碰撞，不唯一 |
| `40003` | 群内消息序号 | 群内有序，可跨群复用 |
| `40050` | Unix 秒级发送时间戳 | 时间字段，无唯一性 |

## 关联字段

| 字段 | 关系 |
|------|------|
| `40001` | 数据库唯一主键；不可由 `40002` 替代 |
| `40003` | 群内顺序字段；与 `40002` 没有单调关系 |
| `40013` | 随机数在各方向均可出现，不能用方向解释其唯一性 |
| `40050` | 与时间无显著线性相关，不是时间编码字段 |

## 结论

`40002` 是消息随机数/去重随机值，字段总体置信度为 **✅ 高**。可以确认其随机、高基数、允许碰撞的字段性质；“用于服务端 ACK 匹配”等具体协议用途仍应标记为推测。
