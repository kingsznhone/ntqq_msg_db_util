# 字段 `40093` — 发送者默认昵称

| 属性 | 值 |
|------|-----|
| 字段编号 | 40093 |
| 类型 | TEXT |
| 所属表 | `group_msg_table` |
| 置信度 | ✅ 高 |

## 含义

`40093` 是群消息中的发送者默认昵称字段。当发送者没有设置群名片，或群名片字段未提供时，客户端使用该字段作为回退显示名称。

外部资料对该字段的版本差异说明采信度较高：旧版记录中该字段可能为空；NT 版本中，在未设置群名片时使用默认昵称。该结论与当前数据库中的昵称回退分布一致。

## 与 `40090` 的关系

- `40090` 更偏向用户设置的群名片/群昵称；
- `40093` 更偏向默认昵称或回退显示名；
- 两者并非绝对互斥，特殊消息和迁移记录可能违反这一模式。

## 结论

`40093` 是发送者默认昵称/显示名回退字段，置信度为 **✅ 高**。旧版可能为空、NT 中用于群名片缺失时回退的版本差异作为字段兼容规则记录。
