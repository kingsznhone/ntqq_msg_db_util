# 字段 `40021` — 群聊对象 ID

| 属性 | 值 |
|------|-----|
| 字段编号 | 40021 |
| 类型 | TEXT |
| 所属表 | `group_msg_table` |
| 置信度 | ✅ 高 |

## 含义

`40021` 是群聊会话对象 ID，在 `group_msg_table` 中实际存储为**十进制群号字符串**。它不是发送者 NT UID，也不是 `u_` 格式的 NT UID。

## 统计证据

基于 `540,018` 行群消息：

- distinct：`33`；
- 全部 `540,018` 行都是纯数字字符串；
- 字符串长度分布：6 位 `25,898` 行、9 位 `293,438` 行、10 位 `220,682` 行；
- 非零群号记录中，`40021` 与 `40030` 的文本值 100% 相等；
- `40027` 与 `40021` 稳定一对一对应；
- `40021` 与 `40020` 在本人发送方向全部不同。

## 与群号 `40030` 的关系

| 场景 | 关系 |
|------|------|
| `40030` 非零 | `40021` 等于 `40030` 的十进制字符串形式 |
| `40030=0` | `40021` 仍为数字字符串，通常代表特殊/系统对象或异常记录 |
| 同一群的多条消息 | `40021` 保持不变，不随发送者变化 |

因此，`40021` 和 `40030` 是同一群聊对象的不同存储类型：前者为 TEXT，后者为 INTEGER。

## 与发送者字段的关系

- `40020` 是实际发送者 NT UID；
- `40033` 是实际发送者 QQ；
- 同一群中多个发送者共享同一个 `40021`；
- `40013=1/2` 的本人发送消息中，`40020=40021` 不成立；
- 收到方向中少量相等记录属于系统/历史/字段复用边界，不改变主体规律。

## 与会话键的关系

`40027` 是本地会话键，`40021` 是会话对象的字符串标识。当前数据中：

- 一个 `40027` 对应一个 `40021`；
- 一个 `(40027,40030)` 组合对应一个 `40021`；
- 这支持 `40021` 作为群聊对象标识，而不是消息级发送者字段。

## 关联字段

| 字段 | 关系 |
|------|------|
| `40020` | 发送者 NT UID，与 `40021` 角色不同 |
| `40027` | 本地会话键，与 `40021` 稳定对应 |
| `40030` | 群号 INTEGER，与 `40021` 数值内容对应 |
| `40033` | 发送者 QQ，同一群可有多个值 |
| `40003` | 群内消息序号，按群对象分区 |

## 结论

`40021` 是群聊对象 ID，在当前表中以十进制群号字符串存储，置信度为 **✅ 高**。
