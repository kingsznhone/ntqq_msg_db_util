# 字段 `40027` — 本地群聊会话键

| 属性 | 值 |
|------|-----|
| 字段编号 | 40027 |
| 类型 | INTEGER |
| 所属表 | `group_msg_table` |
| 置信度 | ✅ 高 |

## 含义

`40027` 是客户端为群聊对象分配的本地会话键/会话分区 ID。它不是群号本身，也不是消息唯一 ID，而是用于在本地数据库中组织和定位某个群聊会话。

## 统计证据

基于 `540,018` 行群消息：

- distinct：`33`；
- 非正值：`0`；
- 每个 `40027` 对应不超过一个 `40021`：`33/33`；
- 每个非零 `40030` 对应不超过一个 `40027`：`30/30`；
- 主要会话中，一个 `40027` 对应一个非零群号，并可能附带 `40030=0` 的特殊记录。

## 与群内序号 `40003` 的关系

按 `40027` 分组、再按 `40050` 排序后：

- `40003` 非递减：`539,978 / 539,985`；
- 非递减比例约为 `100%`；
- 严格递增比较：`536,113`。

这说明 `40027` 是群内消息序号 `40003` 的稳定分区键。少量非递增比较可能来自相同时间、批量写入或特殊记录。

## 与其他会话字段的关系

| 字段 | 关系 |
|------|------|
| `40021` | 群聊对象 ID，TEXT 类型的十进制群号字符串；与 `40027` 稳定对应 |
| `40030` | 群号，INTEGER 类型；非零值与 `40027` 稳定对应 |
| `40003` | 群内消息序号；按 `40027` 分区后随时间推进 |
| `40058` | 日期索引；数据库存在以 `40027` 为前导列的日期索引 |
| `40001` | 消息唯一 ID；不由 `40027` 生成 |

## 与数据库索引的关系

本表索引直接体现了 `40027` 的会话分区作用：

- `(40027, 40003)`
- `(40027, 40003, 40002)` 唯一索引
- `(40027, 40058)`
- `(40011, 40012, 40027)`

## 结论

`40027` 是本地群聊会话键/会话分区 ID，置信度为 **✅ 高**。它用于关联群聊对象、群内消息序号和日期索引，不应当作群号或消息主键使用。
