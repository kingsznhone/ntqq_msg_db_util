# 字段 `40041` — 消息发送/处理状态

| 属性 | 值 |
|---|---|
| 字段编号 | `40041` |
| 类型 | INTEGER |
| 置信度 | 🔍 中（主值）/ ❓ 低（少数值） |

## 结论

`40041` 是消息发送或处理状态字段。它覆盖收到消息、本人发送、系统消息和多种内容类型，因此不是消息类型或方向字段。

## 取值分布

| 值 | 行数 | 当前结论 | 置信度 |
|---:|---:|---|---|
| `2` | 540,015 | 默认/正常处理状态 | 🔍 |
| `3` | 2 | 特殊处理状态 | ❓ |
| `0` | 1 | 特殊处理状态 | ❓ |
| `1` | 0 | 当前无样本 | 未知 |

## 使用边界

- 当前数据不能把 `0`、`1`、`3` 分别命名为阻止、未发送或被和谐。
- `40041=2` 只能作为正常处理的高覆盖提示，不能证明消息已送达或已读。
- 联合 `40013`、`40040`、`40105` 使用；这些字段的角色不同。
