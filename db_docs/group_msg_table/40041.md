# 字段 `40041` — 消息发送/处理状态

| 属性 | 值 |
|------|-----|
| 字段编号 | 40041 |
| 类型 | INTEGER |
| 所属表 | `group_msg_table` |
| 置信度 | 🔍 中 |

## 含义

`40041` 是消息发送或处理状态字段的候选。当前数据能够确认它不是消息类型、同步标志或已读/送达标志；但由于非主值样本极少，具体枚举含义仍需后续数据库或发送失败样本验证。

## 取值分布

基于 `540,018` 行群消息：

| 值 | 行数 | 当前解释 | 置信度 |
|---:|-----:|----------|--------|
| `2` | 540,015 | 正常成功/已处理状态 | 🔍 中 |
| `3` | 2 | 特殊异常/处理状态 | ❓ 低 |
| `0` | 1 | 特殊失败或未完成状态 | ❓ 低 |

## 交叉验证

- `40041=2` 覆盖收到消息、本人发送、系统消息、回复、文件、视频和合并转发等多种类型，说明它表达的是处理/状态结果，而不是消息类别。
- 非 `2` 的 3 条记录均出现在特殊发送方向：`40041=0` 出现在 `40013=5`，`40041=3` 出现在 `40013=1` 和 `40013=5`。
- `40040=1` 中 99.93% 仍为 `40041=2`，两者不等价。
- `40105` 与 `40041` 也不等价；`40105` 更像发送侧确认或送达候选字段。

## 解释边界

当前不能可靠地将：

- `0` 命名为发送失败；
- `1` 命名为发送中；
- `3` 命名为被和谐或处理异常。

这些解释需要更多真实失败、重试或服务端拒绝样本。

## 关联字段

| 字段 | 关系 |
|------|------|
| `40013` | 非 `2` 状态集中于特殊发送/来源方向 |
| `40040` | NT 同步/来源流程标志，与 `40041` 不等价 |
| `40009` | 批量/转发标志，不能单独解释状态 |
| `40105` | 发送侧确认/送达候选字段，与 `40041` 角色不同 |
| `40011`、`40012` | 消息类型和子类型；`40041=2` 覆盖所有主要类型 |

## 结论

`40041` 暂定为消息发送/处理状态字段，置信度为 **🔍 中**。`40041=2` 可暂解释为正常成功/已处理；`0/3` 的具体含义保持低置信度。
