# 字段 `40062` — 表态/Reaction 明细 BLOB
 
## 结论

`40062` 是与消息表态/Reaction 相关的嵌套 Protobuf BLOB，保存表态明细或结构化摘要，不是普通消息正文。

当前可稳定使用的结论是“属于表态数据体系”。内部 `48301` 仍是多态 payload，因此不把 `48302/48303` 强行命名为表情 ID、数量或操作者 ID。

## 统计

基于 `540,018` 行：

- 非 NULL：`1,960` 行，约 `0.36%`；
- 所有非 NULL BLOB 均可由 wire parser 读取；
- 常见结构包含重复的 `40062` 条目，以及 `48301`、`48302`、`48303`、`48304`；
- `48302` 当前主要为 `1/2`，`48303` 主要为 `1/2/3/4/5`，`48304` 几乎恒为 `0`。

典型结构：

```text
40062 -> 48301 (nested bytes)
         48302 (varint)
         48303 (varint)
         48304 (varint)
```

单个 BLOB 可以包含多个 `40062` 条目。

## 与 `40083/40084` 的关系

- `40062` 非 NULL 与 `40083/40084` 非零高度同步，但存在少量例外；
- `40083` 与 `40084` 在 `540,015` 行中相等，仅 `3` 行不相等；
- 因此二者可以作为 Reaction 相关摘要字段读取，但当前不能确定各自统计维度。

## 消息类型范围

非 NULL 记录主要出现在 `40011=2` 和 `40011=9`，也出现在 `7/8/11/17` 等特殊类型。因此不能把它限定为某一种外层消息类型。

## 读取建议

- 保留每个 `40062` 条目的原始顺序和原始 bytes；
- 已知 varint 字段可以读取数值，但不要依赖 `48302/48303` 的具体业务命名；
- 与 `40083/40084` 联合判断是否存在 Reaction 摘要；
- 需要继续研究时，从 `48301` payload 的样本聚类开始。

## 关联字段

| 字段 | 关系 |
|---:|---|
| `40083`、`40084` | Reaction 相关整数摘要 |
| `40011`、`40012` | 外层消息类型和属性 |
| `40850` | 部分 Reaction/回复记录的关联序号 |
| `40900` | 可能保存关联消息快照 |

## 研究边界

当前不确认：`48302/48303` 的字段分工、`40083/40084` 的统计维度，以及是否存在操作者 UID、时间和目标消息等附加信息。
