# 字段 `40062` — 表态/Reaction 明细 BLOB

| 属性 | 值 |
|------|-----|
| 字段编号 | 40062 |
| 类型 | BLOB |
| 所属表 | `group_msg_table` |
| 置信度 | 🔍 中 |

## 含义

`40062` 是与消息表态/Reaction 相关的嵌套 protobuf BLOB，保存表态明细或其结构化摘要。它不是随机二进制，也不是普通消息正文。

当前只能确认其属于表态/Reaction 数据体系，内部字段的具体产品语义尚未完全还原。

## 统计证据

基于 `540,018` 行群消息：

- 非 NULL：`1,960` 行，占 `0.36%`；
- BLOB 长度分布较分散，常见长度为 22、23、25、26 字节；
- 全部非 NULL BLOB 均可由自定义 protobuf wire parser 解析；
- 主体结构为重复的 `40062` 字段，每个条目通常包含嵌套字段 `48301`，以及 `48302`、`48303`、`48304` 等字段。

## 内部结构

常见条目形态：

```text
40062 -> 48301 (nested bytes)
         48302 (varint)
         48303 (varint)
         48304 (varint)
```

当前观察到：

- `48302` 主要取值为 `1/2`；
- `48303` 主要取值为 `1/2/3/4/5`；
- `48304` 几乎恒为 `0`；
- 单个 BLOB 可以重复包含多个 `40062` 条目。

这些字段可能分别代表表态类型、表情编号、数量或预留状态，但尚未进行可靠命名。

## 与 40083/40084 的关系

- `40083`、`40084` 非零时，`40062` 通常同时非 NULL；
- `40062` 非 NULL 与整数统计字段高度同步，但存在少量例外；
- `40083` 与 `40084` 在 `540,015` 行中相等，仅 3 行不相等；
- 三条差异记录中的 BLOB 条目数分别为 1、2、7，不能简单解释为两个整数值。

因此，`40083/40084` 更可能是从 `40062` 明细或同一 Reaction 状态中提取出的摘要字段，但目前无法确认具体统计维度。

## 与消息类型的关系

`40062` 非 NULL 记录覆盖多个消息类型，主要包括：

- `40011=2`：普通消息及媒体消息；
- `40011=9`：回复/Reaction 相关消息；
- `40011=7/8/11/17`：视频、转发、合并转发或状态类消息。

因此暂不能把 `40062` 限定为只服务于 `40011=9`。

## 解释边界

当前不能确认：

- `48302`、`48303` 是否分别为表情 ID 和数量；
- `40083`、`40084` 哪一个是总数或当前用户状态；
- `40062` 是否还保存操作者 UID、时间或目标消息信息；
- 该结构是否完全等同于 Reaction，还是通用消息表态缓存。

## 关联字段

| 字段 | 关系 |

| `40083` | 表态统计摘要候选 |
| `40084` | 表态统计摘要候选 |

| `40851` | 关联消息时间戳候选；本轮未发现与所有 40062 记录同步 |

## 结论

`40062` 是结构化表态/Reaction 明细 BLOB，置信度为 **🔍 中**。内部 protobuf 字段可继续逆向，但当前阶段不再对 `48302/48303` 和 `40083/40084` 的具体统计含义做更强推断。
