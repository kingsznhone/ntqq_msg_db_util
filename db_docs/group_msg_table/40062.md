# 字段 `40062` — 表态/Reaction 明细 BLOB
 
## 结论

`40062` 仅存在于 `group_msg_table`，是与消息表态/Reaction 相关的嵌套 Protobuf BLOB，不是普通消息正文。外层使用可重复字段 `40062`，每个条目记录一种成员表态的表情及其状态、数量信息。

当前已能稳定解释其常见内部字段：`48301` 为表情 ID，`48302` 为表态标志，`48303` 为该表情的表态数量，`48304` 表示本账号是否也贴了该表情。`48302` 的具体枚举值含义仍未完全确认。

## 统计

基于 `540,018` 行：

- 非 NULL：`1,960` 行，约 `0.36%`；
- 所有非 NULL BLOB 均可由 wire parser 读取；
- 常见结构包含重复的 `40062` 条目，以及 `48301`、`48302`、`48303`、`48304`；
- `48301` 为字符串：小黄脸系表情使用数字编号，emoji 系表情使用对应 Unicode 码点；
- `48302` 当前主要为 `1/2`，疑似表示该表情是否处于已表态状态；
- `48303` 为贴该表情的成员人数；
- `48304` 为布尔值，`true` 表示本账号也贴了该表情。

典型结构：

```text
40062 -> 48301 (string)
         48302 (varint)
         48303 (varint)
         48304 (bool)
```

单个 BLOB 可以包含多个 `40062` 条目。`48301` 的表情编号与 [QQBOT 表情编号](https://bot.q.qq.com/wiki/develop/api-v2/openapi/emoji/model.html) 对应，超级表情不在此列表中。

## `40062` 值解读（贴表情）

每个重复的 `40062` 子结构对应一种成员表态的表情，字段如下：

| Field Number | 类型 | 含义 | 说明 |
| --- | --- | --- | --- |
| `48301` | string | 表情 ID | 与 [QQBOT 表情编号](https://bot.q.qq.com/wiki/develop/api-v2/openapi/emoji/model.html) 对应；小黄脸系表情为数字编号，emoji 系表情为对应 Unicode 码点（超级表情不在此列表中） |
| `48302` | int | 表态标志 | 疑似标记该表情是否处于已表态状态 |
| `48303` | int | 表态数量 | 贴该表情的成员人数总和 |
| `48304` | bool | 是否本人所贴 | `true` 表示本账号也贴了该表情 |

> [!TIP]
> 表中的列 `40083`、`40084`（表态表情数量总和）与本结构的 `48303` 数量相呼应，为便于统计而冗余存储的整型值。

## 与 `40083/40084` 的关系

- `40062` 非 NULL 与 `40083/40084` 非零高度同步，但存在少量例外；
- `40083` 与 `40084` 在 `540,015` 行中相等，仅 `3` 行不相等；
- 二者均可作为该消息的表态表情数量总和读取；在当前快照中二者几乎完全同步。

## 消息类型范围

非 NULL 记录主要出现在 `40011=2` 和 `40011=9`，也出现在 `7/8/11/17` 等特殊类型。因此不能把它限定为某一种外层消息类型。

## 读取建议

- 保留每个 `40062` 条目的原始顺序和原始 bytes；
- `48301`、`48303`、`48304` 可按上述字段定义读取；`48302` 可读取数值，但具体枚举含义仍需结合更多版本样本验证；
- 与 `40083/40084` 联合判断是否存在 Reaction 摘要；
- 需要继续研究时，从 `48301` payload 的样本聚类开始。

## 关联字段

| 字段 | 关系 |
|---:|---|
| `40083`、`40084` | 表态表情数量总和，与各条目的 `48303` 相呼应 |
| `40011`、`40012` | 外层消息类型和属性 |
| `40850` | 部分 Reaction/回复记录的关联序号 |
| `40900` | 可能保存关联消息快照 |

## 研究边界

当前不确认：`48302` 各枚举值的精确含义，以及是否存在操作者 UID、时间和目标消息等附加信息。
