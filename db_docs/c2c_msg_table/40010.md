# 字段 `40010` — 聊天类型（chatType）

| 属性 | 值 |
|------|-----|
| 字段编号 | 40010 |
| 类型 | INTEGER |
| 所属表 | c2c_msg_table |
| 主键 | — |
| 置信度 | 🔍 中 |

## 含义

`40010` 更符合 NTQQ 的 **chatType（聊天类型）** 定义，而不是协议格式标志。当前 C2C 表中绝大多数值为 `1`，group 表全量为 `2`；这与“私聊=1、群聊=2”的跨表证据一致。

group 表的对应字段全量为 `2`，与“私聊=1、群聊=2”的跨表解释一致。其他会话类型不在当前样本范围内。

## 取值说明

| 值 | 行数 | 占比 | 当前解释 |
|----|------|------|----------------|
| `1` | 1,340,960 | 99.91% | 私聊；C2C 的默认取值 | ✅ 高 |
| `100` | 211 | 0.016% | 特殊会话类型；具体名称未定 | 🔍 中 |
| `103` | 286 | 0.021% | 其他接收型会话/控制路径；名称未定 | ❓ 低 |
| `114` | 5 | 0.0004% | 未知边界值 | ❓ 低 |

group 表补充验证：`group_msg_table.40010` 全部 `540,018` 行为 `2`。

## 使用边界

- `1` 和 group 的 `2` 可直接用于当前两张表的会话分类。
- `100/103/114` 仅保留原始值和低置信度解释，不按未经验证的产品名称分支。
- 本字段不应再命名为“消息协议格式标志”。
|------|------|
| 总行数 | 1,318,588 |
| 不重复值数 | 4 |
| NULL 行数 | 0 |
| 值域 | 1 ~ 114 |

## 关联字段

| 字段 | 关系 |
|------|------|
| `40011` | 不同 chatType 下的消息类型分布不同；`103` 样本包含 `40011=11` 和 `1`，不能仅凭消息类型确认其为公众号 |
| `40012` | 值=103/114 时 40012 恒为 `0` |
| `40013` | `100` 同时存在收发方向；`103/114` 当前样本均为接收方向 |
| `40800` | `103/114` 含无消息体记录，但 `103` 并非所有记录都可据此定义；`100` 同时存在有消息体记录 |

## 验证方法

- 对比值为 `103` 的 `40011=11` 与无消息体记录，确认是否属于公众号消息而非控制通知
- 对比值为 `114` 的完整元数据，确认其是否为迁移噪音或其他 chatType
- 在包含频道、公众号、企业客服的其他消息表中验证 `4/102/103` 的一致性

## 说明

- `1` 与 C2C、`2` 与 group 的跨表分布为聊天类型解释提供了较强支持
- `100` 与临时会话候选一致，但仍需其他会话表验证
- `103` 和 `114` 的当前样本不足，不能仅凭数值直接提升为高置信度
- 本字段不应再优先命名为“消息协议格式标志”；旧解释作为历史假说保留在本报告的边界说明中
