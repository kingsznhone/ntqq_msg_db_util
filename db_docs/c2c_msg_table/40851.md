# 字段 `40851` — Reaction 发送时间戳

| 属性 | 值 |
|------|-----|
| 字段编号 | 40851 |
| 类型 | INTEGER |
| 所属表 | c2c_msg_table |
| 主键 | ✗ |
| 置信度 | ✅ 高 |

## 含义

在 C2C 表中，`40851` 是 Reaction 行为发出的 Unix 秒级时间戳。它与 `40850` 配对使用，其他消息类型通常为 `0`。

## 取值说明

| 值 | 含义 | 说明 |
|----|------|------|
| `0` | 无时间戳 | 非 Reaction 消息，占 99.9% |
| `~1.7×10⁹` | Reaction 发送的 Unix 时间戳（秒） | 仅出现于 `40011=9` 的 Reaction 行 |

## 取值分布

| 类别 | 行数 | 占比 |
|------|------|------|
| 值为 `0` | 1,316,792 | 99.9% |
| 非零（Reaction 时间戳） | 1,796 | 0.1% |
| 非零值域 | 1,721,450,772 ~ 1,778,504,232 | 共 1,735 个唯一值 |
| 对应时间范围 | 2024-07 ~ 2026-05 | — |

## 与 40850 的共现关系

（限于 `40011=9` 的 Reaction 消息）

| 情况 | 行数 |
|------|------|
| 40850 和 40851 均非零 | 1,792 |
| 仅 40850 非零 | 0 |
| 仅 40851 非零 | 2 |
| 两者均零 | 0 |

两字段几乎完全同步出现（共现率 99.9%），构成 Reaction 消息的核心元数据对。

## 关联字段

| 字段 | 关系 |
|------|------|
| `40011` | 40851 != 0 ↔ 40011=9（Reaction） |
| `40850` | 配对字段：40850 存储被反应原消息的 clientSeq，40851 存储 Reaction 发出时间 |

## 使用边界

- 用 `40851` 作为 Reaction 发生时间，不要将其解释为被反应原消息的发送时间。
- group 的 `40851` 当前全量为 0，不能套用 C2C 语义。
