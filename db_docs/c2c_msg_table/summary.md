# c2c_msg_table 字段速查

> 数据源：`nt_msg_plain.db` / `c2c_msg_table`，本页统计基线为 `1,318,588` 行。数字是该数据库快照的统计结果，不代表所有 QQ/NTQQ 版本。
>
> 置信度：✅ 已验证；🔍 当前数据支持的解释；❓ 仅确认结构或样本不足；未知：没有可靠语义。

## 使用入口

- 读取消息正文和媒体内容：先看 [`40800.md`](40800.md)，再按 `40011` 和 `45002` 选择内部字段。
- 判断方向和发送者：使用 `40013`、`40020`、`40033`。
- 按私聊会话查询：使用 `40027` 分区、`40030` 定位对方。
- 处理引用、Reaction 和缓存：使用 `40850`、`40851`、`40900`。
- 代码解析入口：`msgdb/c2c/`；共享 Protobuf 入口：`msgdb/proto/c2c_40800_parser.py`。
