# 字段 `40030` — 私聊会话对象 QQ

| 属性 | 值 |
|------|-----|
| 字段编号 | 40030 |
| 类型 | INTEGER |
| 所属表 | c2c_msg_table |
| 主键 | — |
| 置信度 | ✅ 高（与 40033/40013 联动验证，与 40027 严格一一对应） |

## 含义

**私聊会话对象 QQ 号**：记录当前私聊会话的对方 QQ 号。与消息发送方向（40013）无关，无论是发出还是收到的消息，40030 始终为该联系人的 QQ 号，不会切换为本人 QQ。

## 取值说明

| 特征 | 结果 |
|------|------|
| NULL 行数 | 0 |
| 唯一值数 | 561（个私聊联系人） |
| 40030 = owner QQ 的行数 | 309（约 0.02%，疑为自言自语或数据导入异常） |
| 同一 40030 既收又发的联系人数 | 514（验证与方向无关） |

## 与方向的独立性

- 514 个联系人在 40013=0（收到）和 40013=1（发出）两个方向均有记录
- 说明 40030 是**会话维度**的标识，不随消息方向改变

## 与其他字段的对应关系

| 字段 | 关系 |
|------|------|
| `40033` | 40013=0 时 40033 = 40030（对方发来）；40013=1/2 时 40033 = owner QQ（本人发出） |
| `40027` | 与 40030 基本一一对应（同一联系人分配固定本地会话 ID） |
| `40021` | 始终为 40030 对应的 NT UID |

## 关联字段

| 字段 | 关系 |
|------|------|
| `40013` | 消息方向；与 40030 独立，40030 不随方向变化 |
| `40033` | 发送者 QQ；收到时 = 40030，发出时 = owner QQ |
| `40027` | 本地会话 ID，与 40030 严格一一对应 |
| `40021` | 会话对象 NT UID，与 40030 对应 |

## 验证方法

- 同一 40030 在不同方向均有记录：`SELECT 40030 FROM c2c_msg_table WHERE 40013 IN (0,1) GROUP BY 40030 HAVING SUM(40013=0)>0 AND SUM(40013=1)>0`
- 40030 与 40027 一一对应验证：`SELECT 40027, COUNT(DISTINCT 40030) FROM c2c_msg_table GROUP BY 40027 HAVING COUNT(DISTINCT 40030) > 1` → 结果应为 0

## 说明

- 存在约 309 行 `40030 = owner QQ`，推测为自言自语（给自己发消息）或极旧历史数据导入时的字段错位，占比极小（0.02%）。
- 40027 与 40030 存在 29 对多映射，与上述异常数据相关。
