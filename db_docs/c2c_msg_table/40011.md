## 含义

**消息内容类型（Content Type）**：标识消息携带的是哪种媒体或交互内容，类似 MIME type。决定了 `40012` 的可取值空间。

## 关键规律

- **`40011` 决定 `40012` 的可取值空间**：`40011≠2` 时，`40012` 几乎固定为某个特定值，不是自由组合的位掩码
- `40011=2` 是唯一一种 `40012` 真正作为 bitmask 自由叠加的情况
- bit12（`0x1000`，长消息标志）**仅在 `40011=2` 下出现**，其他类型均不含此 bit
