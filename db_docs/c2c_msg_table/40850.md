# 字段 `40850` — Reaction 目标消息的 clientSeq

| 属性 | 值 |
|------|-----|
| 字段编号 | 40850 |
| 类型 | INTEGER |
| 所属表 | c2c_msg_table |
| 主键 | ✗ |
| 置信度 | ✅ 高 |

## 含义

在 C2C 表中，`40850` 记录 Reaction 所指向的原消息 `clientSeq`，即目标消息的 `40005`。非零值几乎只出现在 `40011=9` 的 Reaction 行。

## 取值说明

| 值 | 含义 | 说明 |
|----|------|------|
| `0` | 无引用 | 非 Reaction 消息，占 99.86% |
| `33 ~ 65312` | 被反应原消息的 clientSeq | 仅出现于 `40011=9` 的 Reaction 行 |

## 取值分布

| 类别 | 行数 | 占比 |
|------|------|------|
| 值为 `0` | 1,316,794 | 99.86% |
| 非零（Reaction 引用） | 1,794 | 0.14% |
| 非零值域 | 33 ~ 65312 | 共 1,714 个唯一值 |

值分布在两段：低段（33~29995，936 条）和高段（30037~65312，858 条），符合 `clientSeq` 为 uint16 循环计数器的特征。

## 关联字段

| 字段 | 关系 |
|------|------|
| `40011` | 40850 != 0 ↔ 40011=9（Reaction），重合率 99.9% |
| `40005` | 40850 的值等于被反应原消息的 40005（clientSeq） |
| `40030` | 与 40850 联合定位原消息：同一 peer + clientSeq = 40850 |

## 验证方法

在同会话（`40030` 相同）内，查找 `40005 = 40850` 且 `40050 ≤` Reaction 发送时间的非 Reaction 消息，可定位被反应的原始消息。

全量目标匹配结果（1,792 条 Reaction）：
- 精确匹配（唯一原消息）：1,354 条（75.6%）
- 多候选（同 peer+clientSeq 有多条历史消息）：430 条（24.0%）
- 未找到：8 条（0.4%，目标不在当前本地数据范围内）

## 说明

- `clientSeq`（40005）为 uint16 循环计数器，上限 65535，故 40850 值域完全落在 [0, 65535] 内
- 2 条 `40011=5` 的行也有非零 40850，属于边缘情况，不影响整体判断
- 多候选情况（24%）来自 clientSeq 循环复用，需结合时间和其他字段消歧
