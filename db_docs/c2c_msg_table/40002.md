# 字段 `40002` — 消息随机数

| 属性 | 值 |
|---|---|
| 字段编号 | `40002` |
| 类型 | INTEGER |
| 置信度 | ✅ 高 |

## 结论

`40002` 是客户端生成的消息随机数（`msgRandom`），用于协议侧去重或 ACK 匹配。它不是唯一键。

## 关键统计

| 特征 | 结果 |
|---|---|
| 总行数 | `1,318,588` |
| 不重复值数 | `1,303,292` |
| 与 `40050` 的单调关系 | 约 `49.8%`，无时间顺序 |
| 与 `40001` | Pearson 约 `0.099`，基本独立 |
| 主要值域 | 多数为 32 位随机数；少量 NT 记录扩展为 64 位 |

重复值是随机空间中的自然碰撞，跨会话出现时不表示消息关联。值为 `0` 的少量异常记录应结合时间和其他字段判断。

## 使用边界

- 只能与 `40001` 或其他上下文联合使用，不能单独定位消息。
- 数据库的 `(40027, 40002, 40005)` 唯一索引反映的是存储去重约束，不改变 `40002` 本身不是全局唯一键的事实。
