# 字段 `40008` — 协议保留字段

| 属性 | 值 |
|------|-----|
| 字段编号 | 40008 |
| 类型 | INTEGER |
| 所属表 | c2c_msg_table |

| 置信度 | ❓ 低（值恒为 0，无法确认实际语义） |

## 含义

**NT 新协议保留整数字段**：在 2025-11 之前的全部历史记录中为 NULL；2025-12 起随 NT 协议升级批量写入，但值固定为 `0`，无任何区分信息，推测为预留扩展字段。

## 取值说明

| 值 | 含义 | 说明 |
|----|------|------|
| `NULL` | 旧协议记录 | 2025-11 之前全部为 NULL |
| `0` | 默认 / 保留 | 目前唯一出现的非 NULL 值，无语义区分 |
