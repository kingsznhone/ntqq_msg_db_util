# 字段 `40003` — 全局倒序序号

| 属性 | 值 |
|---|---|
| 字段编号 | `40003` |
| 类型 | INTEGER |
| 置信度 | ✅ 高 |

## 结论

`40003` 是跨会话共用的倒序消息序号：值越大通常越旧，值越小通常越新。它不是主键，也不是会话内独立序号。

## 关键统计

| 特征 | 结果 |
|---|---|
| 值域 | `0`–`151,237` |
| 不重复值数 | `53,907`；多条消息可以共享值 |
| 跨会话范围 | 存在重叠 |
| 按 `40050` 升序的单调递减比例 | `100%` |
| `0` 值 | 大量会话固定为 0 |

## 使用边界

- 用 `40001` 作为消息唯一定位键。
- `40003=0` 表示该记录没有可用的此类序号，不能据此推断消息不存在。
- group 表中的 `40003` 是群内消息序号，不能直接套用本页 C2C 解释。
