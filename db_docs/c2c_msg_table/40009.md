# 字段 `40009` — 批处理/批量转发标志

| 属性 | 值 |
|---|---|
| 字段编号 | `40009` |
| 类型 | INTEGER |
| 置信度 | 🔍 中 |

## 结论

`40009` 的非 NULL 值只出现在 NT 新协议时期；绝大多数为 `0`，仅 `14` 行为 `1`。这些非零记录均为本人发送侧，并集中于合并转发或同批次多目标发送场景，因此当前按批处理/批量转发标志读取。

## 统计

| 值 | 行数 | 占非 NULL |
|---:|---:|---:|
| NULL | 1,279,494 | — |
| `0` | 39,080 | 99.96% |
| `1` | 14 | 0.04% |

`40008` 与本字段的 NULL/非 NULL 模式完全同步，二者应视为同一协议版本字段组的一部分。

## 使用边界

- `40009=1` 可以作为批处理记录的强提示，但样本量不足以定义所有批处理场景。
- 不要把 `40009=0` 等同于“绝对不是转发”；它只表示当前样本中的默认路径。
