# 字段 `40009` — 批量转发标志

| 属性 | 值 |
|------|-----|
| 字段编号 | 40009 |
| 类型 | INTEGER |
| 所属表 | c2c_msg_table |
| 主键 | — |
| 置信度 | 🔍 中（基于 14 条样本的行为模式推断，逻辑自洽） |

## 含义

**批量多目标转发标志**：在 2025-11 之前的全部历史记录中为 NULL；2025-12 起随 NT 协议升级引入。绝大多数消息为 `0`（普通单目标发送）；`1` 出现在同一批次将消息（多为合并转发包）同时转发给多个不同联系人的场景，且发送者均为本人，`40013 ∈ {4, 5}`。

## 取值说明

| 值 | 含义 | 说明 |
|----|------|------|
| `NULL` | 旧协议记录 | 2025-11 之前全部为 NULL |
| `0` | 普通发送 | 99.96% 的非 NULL 行；单目标常规消息 |
| `1` | 批量多目标转发 | 14 条；发送者本人，消息类型多为合并转发（40011=11）或普通消息（40011=2, 40012=2），40013 为 `4` 或 `5`；同一批次消息在数秒内发往多个不同联系人 |

- 若 40009=1 持续只出现在 40013 ∈ {4, 5} 的行，可进一步确认与消息转发批次的绑定关系。
