# 字段 `40021` — 会话对象 NT UID

| 属性 | 值 |
|------|-----|
| 字段编号 | 40021 |
| 类型 | TEXT |
| 所属表 | c2c_msg_table |
| 主键 | — |
| 置信度 | ✅ 高（统计规律强，无协议文档直接验证） |

## 含义

**本次私聊会话对方的 NT UID**：始终存储 `40030`（会话对象 QQ）所对应的 NT UID，与消息发送方向无关。无论消息是收到还是发出，40021 都代表「聊天窗口另一侧的人」的 UID，而非接收者。

## 取值说明

| 格式 | 说明 |
|------|------|
| `u_XXXXXXXXXXXXXXXXXXXXXX` | `u_` 前缀 + 22 字节 Base64url 编码，总长 24 字符 |

## 统计特征

| 特征 | 结果 |
|------|------|
| 总行数 | 1,318,588 |
| 不重复值数 | 560 |
| NULL 行数 | 0 |
| QQ → UID 对应关系 | 严格一一对应（唯一例外：QQ=0 的系统消息有 29 个 UID） |

## 与方向（40013）的关系

| 40013 | 40021 含义 |
|-------|-----------|
| `0`（接收） | 对方的 NT UID（== 40020，因为发送者即会话对象） |
| `1`（发送） | 收件人（对方）的 NT UID，DB owner 的 UID 几乎不出现 |
| `2`（发送特殊） | 同上 |
| `3`（系统） | 系统账号 UID |

## 关联字段

| 字段 | 关系 |
|------|------|
| `40030` | 严格一一对应：40021 是 40030（会话对象 QQ）的 NT UID |
| `40020` | 接收消息时 40021 == 40020；发送消息时 40021 为对方 UID，40020 为 owner UID |
| `40013` | 决定 40021 与 40020 是否相等 |

## 说明

- 此字段含义可理解为「私聊会话的对端 UID」，而非严格意义上的「消息接收者 UID」
- DB owner 的 UID（`u_B5T2****`）在 40021 中极少出现（各方向占比均 < 0.1%），进一步确认 40021 ≠ 接收者字段
- NT UID 与 QQ 号在此数据库范围内严格一一映射
