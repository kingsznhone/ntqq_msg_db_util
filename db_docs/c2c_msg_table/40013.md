# 字段 `40013` — 消息发送方向

| 属性 | 值 |
|------|-----|
| 字段编号 | 40013 |
| 类型 | INTEGER |
| 所属表 | c2c_msg_table |
| 置信度 | ✅ 高 |

## 含义

**消息发送方向标志**：标识该条消息是由本人发出还是由对方发来。

## 取值说明

| 值 | 含义 | 说明 |
|----|------|------|
| `0` | **对方发送（收到）** | 发送者 QQ（40033）与私聊对象（40030）一致，为收到的消息 |
| `1` | **自己发送** | 发送者 QQ（40033）为本人，正常发出的消息 |
| `2` | **自己发送（特殊类型）** | 发送者同为本人，具体产品差异未定 |
| `3` | **系统消息 / 通知** | 40033 与 40030 均为 `0`，无实际 QQ 号，配合 `40012=12/17` 出现 |
| `4` | **自发消息特殊状态** | 发送者为本人，数量极少 |
| `5` | **自发消息特殊状态** | 发送者为本人，`40012` 全为 `7`，数量极少 |
| 大整数（如 `1367366400`） | **旧版迁移噪音** | 值均为整日 Unix 时间戳（2013～2022 年），与 `40058` 字段含义重叠，系旧版 QQ 数据迁移时写入错误，可忽略 |

## 取值分布（共 1,318,588 行）

| 值 | 行数 | 占比 |
|----|------|------|
| `1`（自己发送）| 642,236 | 48.71% |
| `0`（对方发送）| 632,576 | 47.97% |
| `2`（自发特殊）| 43,492 | 3.30% |
| 其他（噪音 + 系统）| 226 | 0.02% |

## 使用边界

- `0`、`1`、`2` 可结合 `40033` 和 `40030` 区分对方、本人和本人特殊发送。
- `3` 为系统消息；`4/5` 只保留特殊来源含义，不命名为撤回、失败或转发。

## 关联字段

| 字段 | 关系 |
|------|------|
| `40033` | 发送者 QQ，与 `40013` 联合可确认消息方向 |
| `40030` | 私聊对象 QQ，`40013=0` 时与 `40033` 相等 |
| `40012` | 消息标志位，与 `40013=2/3/4/5` 配合可进一步分类 |
