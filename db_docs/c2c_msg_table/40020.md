# 字段 `40020` — 发送者 NT UID

| 属性 | 值 |
|------|-----|
| 字段编号 | 40020 |
| 类型 | TEXT |
| 所属表 | c2c_msg_table |
| 主键 | — |
| 置信度 | ✅ 高（统计规律强，无协议文档直接验证） |

## 含义

**发送该消息的用户在 NT 平台上的 UID**：NT（新技术）协议为每位用户分配唯一的字符串 ID，格式为 `u_` 前缀加 22 个 Base64url 字符。此字段存储实际发送者的 NT UID，与 `40033`（发送者 QQ 号）严格一一对应。

## 取值说明

| 格式 | 说明 |
|------|------|
| `u_XXXXXXXXXXXXXXXXXXXXXX` | `u_` 前缀 + 22 字节 Base64url 编码，总长 24 字符 |

## 统计特征

| 特征 | 结果 |
|------|------|
| 总行数 | 1,318,588 |
| 不重复值数 | 555 |
| NULL 行数 | 0 |
| QQ → UID 对应关系 | 严格一一对应（无一对多） |

## 与方向（40013）的关系

| 40013 | 40020 含义 |
|-------|-----------|
| `0`（接收） | 对方（发送者）的 NT UID，与 40021 相同 |
| `1`（发送） | DB owner 的 NT UID（`u_B5T2****`，99.9%） |
| `2`（发送特殊） | DB owner 的 NT UID（100%） |
| `3`（系统） | 系统账号 UID，非 owner |

## 关联字段

| 字段 | 关系 |
|------|------|
| `40033` | 严格一一对应：40020 是 40033（QQ号）对应的 NT UID |
| `40021` | 接收消息时 40020 == 40021（发送者即会话对象）；发送消息时不同 |
| `40013` | 消息方向决定 40020 的角色（owner UID vs 对方 UID） |

## 说明

- DB owner（QQ 840****14）对应 UID：`u_B5T2****`
- 极少数发送消息（40013=1）中 40020 为非 owner UID（约 731 条），推测为系统代发或历史数据异常
- NT UID 与 QQ 号在此数据库范围内严格一一映射，不存在账号合并或多设备分叉
